# 学习网站设计建议

> 历史方案说明：本文记录最初三个 Demo 的设计建议。当前已实现统一主题与内容驱动的静态站，使用 `content/` + `site/`，不再从 `demos/` 发布。最新操作与架构见 [内容维护与代码结构](site-architecture.md) 和 [项目 README](../README.md)。下文的 Astro/MDX 等是选型建议，非当前已安装的框架。

## 目标

将个人 AI 学习记录发展成可公开阅读、持续扩展、方便分享的网站。读者可以跟随课程逐节学习，也可以直接查阅概念、使用可交互实验。

当前阶段交付三套可打开的原型，原有第一讲 HTML 与 Markdown 笔记完整保留。原型用于比较信息结构与视觉方向，不表示全部课程已完成迁移。

## 三套原型

| 方向 | 主入口 | 阅读方式 | 适用情况 |
| --- | --- | --- | --- |
| 循序 · 课程站 | 学习路线、课程卡片、讲次目录 | 跟着课程往前走 | 新手入门、连续学习 |
| 知页 · 文档站 | 左侧知识目录、正文、页内目录 | 定位某个概念或公式 | 深读、复习、精确分享 |
| 星图 · 地图站 | 有依赖关系的知识节点 | 从关系中选择学习路径 | 跨课程探索、知识回顾 |

三套原型的比较入口：[demos/index.html](../demos/index.html)。

## 推荐：课程引导＋文档阅读＋复用实验

三种入口共用一份内容：

```text
首页
├── 学习路线
│   └── CME295 → 第一讲 → 章节 → 概念
├── 知识库
│   └── 机器学习基础 / 分词 / 注意力 / 架构 / 训练 / 推理
├── 实验室
│   └── 注意力权重 / 梯度下降 / 因果掩码 / 分词示例
└── 知识地图
    └── 按概念的 prerequisites 展示关系
```

同一个“自注意力”页面既可以出现在 CME295 第一讲目录，也可以属于知识库的 Transformer 分类；不需要复制两篇正文。课程页维护阅读顺序，知识页维护正文，实验组件可嵌入多个页面。

## 内容模型

建议使用稳定英文 slug 生成地址，中文标题可自由修改：

```yaml
# concept metadata example
slug: self-attention
title: 自注意力
summary: 用查询匹配键，再按权重汇总值。
level: intermediate
prerequisites:
  - matrices
  - token-embedding
courses:
  - cme295-fall2026
sources:
  - kind: lecture
    lecture: 1
    pages: [58, 62]
status: reviewed
```

正文保留学习偏好：

1. 是什么（清晰定义）
2. 为什么需要（前一种方法的限制）
3. 通俗直觉与图示
4. 一个完整、可核对的计算例子
5. 交互实验
6. 与前后章节的连接
7. 易错点、自测与参考资料

来源材料、课程原意、教学补充需要明确区分。原始 PDF、字幕与参考文档保留在资料目录，公开站点只发布可分享的内容与有权限发布的资料。当前 Demo 构建仅包含 demos/ 页面和资源，不会自动把 PDF、字幕与参考文档发布出去。

## 推荐技术

**Astro＋MDX＋少量交互组件**比较适合当前目标：

- 内容以 Markdown/MDX 和元数据维护。
- 构建生成静态 HTML，正文即使没有 JavaScript 也可读。
- 交互实验作为独立组件嵌入；重要预设提供不依赖脚本的回退内容。
- 用内容集合校验 title、slug、来源、前置知识、课程顺序等字段。
- 用 KaTeX 渲染公式；SVG/Mermaid 用于小型结构图。
- 用 Pagefind 在构建时生成全文搜索，初期不需要搜索后端。
- 主题导航和知识地图来自同一份元数据。

Docusaurus / VitePress 适合更标准的文档产品；如果近期确定需要账户、后台、复杂用户状态，再考虑 Next.js 等应用框架。当前阶段无需为登录系统增加运维成本。

这些是建议，尚未把正式网站绑定到某个框架。原型采用共享 CSS/JS 的多页静态站，可部署验证视觉与交互。

## URL 建议

```text
/                                  首页
/learn/                            学习路线
/courses/cme295-fall2026/           课程目录
/courses/cme295-fall2026/lecture-1/  讲次导读
/concepts/forward-propagation/      概念独立页
/concepts/self-attention/          概念独立页
/labs/attention/                   独立实验
/map/                             知识地图
```

页面保留面包屑、前后篇、当前课程位置、页内目录、来源页码和关联概念。避免原单页中不断增长的分数编号；课程序号由目录生成。

## 部署

### 当前原型

仓库根目录：

```bash
npm run build
python3 -m http.server 8000 --bind 127.0.0.1 --directory dist
```

访问 <http://127.0.0.1:8000/>。构建无需安装 npm 依赖，生成物只有静态页面与资源。

容器方式：

```bash
docker build -t ai-learning-notes:demo .
docker run --rm -p 8080:80 ai-learning-notes:demo
```

访问 <http://127.0.0.1:8080/>。Dockerfile 是多阶段构建，运行镜像使用 Nginx。配置文件位于 [deploy/nginx.conf](../deploy/nginx.conf)。

自己的服务器也可以把 dist/ 上传至 Nginx 文档根目录；再按服务器环境配置域名、HTTPS 和发布脚本。需要先取得服务器位置与访问方式，才能进行真实部署。

### 正式发布过程

1. 编辑 Markdown/MDX 和概念元数据。
2. 检查数值示例、来源、内部链接、内容顺序。
3. 构建静态网站并生成搜索索引。
4. 浏览器检查桌面、手机、禁用脚本及公式显示。
5. 发布至 Nginx/CDN；用稳定 URL 分享。

## 分期实现

| 阶段 | 范围 | 完成标志 |
| --- | --- | --- |
| 第一版 | 课程首页、知识目录、第一讲拆分、数学公式、现有实验、全文搜索、响应式布局、Nginx 发布 | 第一讲可完整阅读，原链接有迁移对应关系 |
| 第二版 | 更多课程、独立实验室、知识地图自动生成、引用与更新记录 | 新增内容主要编辑 Markdown 与元数据 |
| 后续按需 | 本地收藏与进度、可选账户同步、投稿与内容审核、评论 | 基于真实读者需求逐项引入 |

原始笔记不会在选定方向前删除。正式迁移时先生成章节清单与覆盖表，逐项核对定义、例子、图表与来源，避免迁移过程中遗漏内容。

## 当前验证结果

- 静态构建通过。
- 5 个页面在 Chrome 1440px 与 390px 视口中无页面横向溢出。
- 开启与禁用 JavaScript 均可阅读；禁用脚本时注意力预设仍能切换，地图节点可直接导航。
- 主题筛选、示例搜索、地图节点详情、注意力计算通过交互检查。
- 内部文件与锚点目标检查通过；未发现浏览器脚本错误。
- 已检查主要页面截图。
- 本机 Docker daemon 未运行，未执行镜像构建或 Nginx 容器验收；尚未部署到真实服务器。
