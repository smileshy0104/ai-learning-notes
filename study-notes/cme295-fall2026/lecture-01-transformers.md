## 核心问题

Transformer 如何把 token 的初始向量，转换成结合上下文的表示，并用这些表示预测输出 token？

基本流程：

```text
文字 → token ID → token embedding + 位置信息
     → 多层注意力与前馈网络 → 隐藏表示
     → 词表上的分数 → softmax → 下一个 token 的概率
```

原始 Transformer 用编码器处理源语言，用解码器逐步生成目标语言。

### 2010 年代：任务专用的 NLP 模型

NLP 是自然语言处理（Natural Language Processing）。课件第 18 页以三类任务举例：

- 情感分析：把评论分类为正面、负面或中性。
- 机器翻译：把源语言句子转换为目标语言句子。
- 命名实体识别：在文本中标出人名、地名等实体。

当时常见的方式是针对不同任务训练或适配模型。RNN 是重要的序列建模架构之一，能够按顺序处理文本，但训练中的顺序依赖和长距离信息传递会带来限制。后文将具体说明这些限制。

这里是课堂对发展主线的概括，不代表当时所有方法都采用 RNN，也不代表每个任务都完全无法共享知识。

### 2017 年：Transformer 架构

课件第 19 页介绍《Attention Is All You Need》。它在机器翻译背景下提出 Transformer，使用自注意力支持位置之间的信息交互，原始架构具有编码器和解码器。

课堂强调可扩展性：在合适的训练配置下，增加参数、数据与计算投入可以进一步改善能力；矩阵形式的计算也适合训练中的并行处理。这里不应理解为只要扩大规模，每项能力就必然改善，数据质量和训练方法仍然关键。

### 2022 年：对话式产品走向大众

课件第 20–21 页以 ChatGPT 发布说明交互方式的转折：用户可以通过自然语言提问、澄清、改写，并通过同一对话接口提出多种任务。

补充理解：这种能力来自架构、训练数据、规模、训练方法及产品设计等共同发展。ChatGPT 是产品名，不能与 Transformer 架构等同。

### 课件所述当下：代理系统

课件第 22 页介绍代理阶段，并以编程工具举例。用修复报错作比较：对话助手可以解释错误和给出建议；具备工具与权限的代理系统还可以读文件、修改代码、运行检查，并根据结果继续工作。

以下循环是教学补充，用于帮助理解代理概念：

```text
接收目标 → 模型决定下一步 → 外部程序执行工具
                  ↑                 ↓
                  └── 获取结果，继续或结束
```

模型负责生成决策与调用信息，外部程序负责实际执行。能力还取决于工具、上下文管理、权限和验证；拥有工具并不保证完成任务。

## 1. Tokenization：文字如何成为模型输入

对应 PDF 第 24–31 页。

分词器将文字切成 token，再把 token 映射为词表中的 ID。ID 是索引，不是语义大小：编号相近不意味着意思相近。

| 方式 | 优势 | 主要代价 |
| --- | --- | --- |
| Word-level | 直观，常见文本序列较短 | 词表大，存在未登录词问题 |
| Character-level | 基础词表较小 | 序列长，计算开销增加 |
| Subword-level | 在词表大小和序列长度间折中 | 效果依赖训练语料和切分规则 |

课堂口头介绍了 BPE（Byte Pair Encoding）：从基础单元出发，反复合并语料中最常见的相邻 token 对，直到满足停止条件。它学习频繁组合，不保证每个组合都是语言学词根。

### 分词器与词表规模

课件只在第 24、27 页标出 Vocabulary 与序列长度，具体量级来自课堂问答。配套 [HTML 图解](lecture-01-visual.html#tokens) 提供可切换的 BPE 合并步骤。

分词器（tokenizer）是独立于神经网络的组件，两个阶段用途不同：

- 训练分词器：从语料统计词表与合并规则。
- 使用分词器：encode 把文字变成 ID，decode 把生成的 ID 变回文字。

词表大小 V 与序列长度 n 相互牵制。以下区间用于建立直觉，具体数值以各模型的分词器说明为准。

| 粒度 | 大致词表规模 | 序列长度 | 主要代价 |
| --- | --- | --- | --- |
| 字符级 | 几十到几百 | 最长 | 位置多，计算与长距离依赖更重 |
| 子词级（主流） | 约 3 万到 20 万 | 中等 | 依赖语料与语言覆盖 |
| 词级 | 可达数十万以上 | 最短 | 未登录词、形态变化导致词表膨胀 |

BPE 的核心机制可以用三个词演示（read ×4、reader ×2、reading ×3）：

| 步骤 | 合并 | read 的切分 | 词表 |
| --- | --- | --- | --- |
| 0 | 无 | r e a d | 7 个字母 |
| 1 | a + d → ad | r e ad | 8 |
| 2 | e + ad → ead | r ead | 9 |
| 3 | r + ead → read | read | 10 |

高频相邻符号对优先合并，词表逐步变大，同一句话的 token 数逐步变少。reader、reading 因此能复用 read 这个符号。真实 BPE 通常从字节开始，并在词边界内统计相邻对。

词表大小直接影响输入嵌入表的参数量 V × d_model。以 d_model = 4096 为例：

| V | 嵌入表参数量 | 说明 |
| --- | --- | --- |
| 32,000 | 约 1.31 亿 | 词表小，序列更长 |
| 50,257 | 约 2.06 亿 | 英文为主的常见量级 |
| 200,000 | 约 8.19 亿 | 单这一层就占很多参数 |

词表很大时，每个符号在训练中出现的次数变少，低频符号的向量难以学好，所以规模是效率、覆盖率与学习效果的折中。总计算量还取决于序列长度：注意力分数矩阵是 n × n。

多语言场景（课堂问答）：分词器在多语言语料上训练时，词表会被各语言分享。只关心单一语言时序列可能变长；跨语言共享的符号也可能带来帮助。做多语言任务应确认分词器覆盖目标语言。

### 特殊 token

对应 PDF 第 28–31 页。词表除了普通文字片段，还预留了带固定含义的特殊 token。配套 [HTML 图解](lecture-01-visual.html#tokens) 提供对照表、[UNK] 示例与填充切换。

| 特殊 token | 名称 | 作用 |
| --- | --- | --- |
| `[UNK]` | Unknown | 表示词表里没有这个片段 |
| `[BOS]` | Beginning of sequence | 标记序列开始，用于启动生成 |
| `[EOS]` | End of sequence | 标记序列结束，模型输出它时应停止 |
| `[PAD]` | Padding | 把短序列补到统一起见长度，填充位置不是真实内容 |

课件示例：假设词表只有 `teddy bear`、`cute bear`、`bear`、`[UNK]` 四项，把 `teddy bear` 误写成 `tedi bear` 时，`tedi` 不在词表中，只能分词为 `[UNK] bear`。

生成示例：输入以 `[BOS]` 开头，输出末尾应当是 `[EOS]`。前者是使用者构造的输入起点，后者是模型需要学会预测的停止信号。

填充示例：句子 A 有 7 个 token，句子 B 有 3 个，补齐到 8 个位置后两者可以堆叠为矩阵。实际训练中通常需要用注意力掩码忽略填充位置，否则这些位置会参与权重分配和损失计算。

补充：

- 不同模型使用不同写法，如 `<s>`、`<|endoftext|>`、`<|start_header_id|>`；对话模型还常出现表示说话角色的 token。使用具体模型时应查它自己的分词器说明。
- 课件未穷举所有约定。现代字节级分词器能把常见拼写片段都映射到词表项，因此普通文本很少真的产生 `[UNK]`。
- `[BOS]`/`[EOS]` 与位置编码、掩码、生成停止条件是不同层次的概念，不能混用。

常见特殊 token：`[UNK]`、`[BOS]`、`[EOS]`、`[PAD]`。名称和使用规则取决于具体模型。使用完整字节覆盖的分词器可以避免一般文本的未登录词问题，因此并非每个现代模型都依赖 `[UNK]`。

## 2. Embedding：从编号到可学习向量

对应 PDF 第 33–44 页。这一节在大纲中称为 Word representation，课件第 33 页的标题是 Token representations。配套 [HTML 图解](lecture-01-visual.html#embedding) 提供 one-hot 与嵌入表的对照。

设词表大小为 V，嵌入维度为 d，嵌入表大小为 V × d。每个 token ID 对应其中一行。

- One-hot：长度为 V，只有对应编号处为 1。不同 token 的点积恒为 0，因此无法表达“意思接近”。
- Embedding：长度为 d 的可学习向量，通常 d 远小于 V。相似性写在数字里，可用点积或余弦相似度衡量。
- 查嵌入表在数学上等价于 one-hot 行向量乘嵌入矩阵，实际实现通常直接索引，避免用几乎全零的向量做乘法。

| 对比项 | One-hot | Learned embedding |
| --- | --- | --- |
| 长度 | V（词表大小） | d（可选超参数） |
| 是否可学习 | 否，写死 | 是，训练中更新 |
| 相似度 | 任意两个都正交，恒为 0 | 可表达“意思接近” |
| 参数量 | 0（只是下标） | V × d |

Word2Vec 通过代理任务学习词向量：CBOW 用上下文预测中心词，Skip-gram 用中心词预测上下文。课件用预测下一个词演示向量学习过程，这是教学简化。

静态词向量的关键限制：同一个词的向量不会随所在句子改变，难以直接区分多义词的当前含义。

## 3. 神经网络结构：Word2vec、RNN、LSTM 与早期注意力

对应 PDF 第 34–55 页。配套 [HTML 图解](lecture-01-visual.html#neural-nets) 重绘了这三类网络结构图，并提供 Word2vec 训练前后的概率对比。

### Word2vec 的网络结构

课件第 35 页只画了三层：输入 V、隐藏层 d、输出 V。隐藏层就是最终使用的词向量，W₁ 尺寸 V × d，W₂ 尺寸 d × V。

训练的不是最终任务，而是代理任务（Skip-gram 用中心词预测上下文，CBOW 用上下文预测中心词）。课件第 36–41 页用句子 “A cute teddy bear is reading” 演示用 “A” 预测 “cute”：

| 项目 | 内容 |
| --- | --- |
| 输入 | “A” 的 one-hot，长度 V = 6 |
| 隐藏层 | d = 2 的可学习向量 |
| 输出 | 6 个概率，经 softmax 归一化 |
| 目标 | “cute” 的 one-hot |
| 损失 | 交叉熵，只关心目标项概率是否接近 1 |

训练若干次后，同一输入下 “cute” 的概率上升，隐藏向量也随之变化，这组向量就是学到的词义表示。

### RNN 与任务形式

RNN 用隐藏状态概括已处理的序列：

\[
h_t=f(h_{t-1},x_t)
\]

课件第 51 页列出 RNN 可承担的任务：生成（文本→文本）、分类（文本→一个类别）、多分类（每个位置一个标签）、情感分析、翻译、命名实体识别。

两个限制：长距离信息要经过多次状态更新，容易被稀释；时间步之间存在依赖，无法并行训练。

### LSTM

LSTM（1997）保留隐藏状态，另加细胞状态，用遗忘门、输入门、输出门控制信息的保留与写入。它缓解长距离依赖，但仍是顺序计算，也没有彻底解决问题。

### 早期注意力（2014）

Bahdanau 等人的工作让解码器在生成每个词时直接读取源句的相关位置。例如生成法语 “lit” 时把注意力指向源句的 “reading”，而不是只靠编码器最后那个状态向量。

这里的注意力连接解码器与编码器，是 cross-attention 的前身；Transformer 的关键变化是把注意力用于同一序列内部（self-attention），并去掉循环结构。

## 4. Self-attention：Q、K、V

对应 PDF 第 57–62 页，以及第 91–101 页的展开示例。

以下公式是结合课程内容给出的标准数学整理，图中符号尚需视觉核对。

设输入 X 的形状为 n × d_model，其中 n 是序列长度。对于单个注意力头：

\[
Q=XW_Q,\quad K=XW_K,\quad V=XW_V
\]

\[
\operatorname{Attention}(Q,K,V)
=\operatorname{softmax}\left(\frac{QK^\top}{\sqrt{d_k}}\right)V
\]

| 对象 | 形状 | 含义 |
| --- | --- | --- |
| X | n × d_model | 每行对应一个位置的输入表示 |
| W_Q、W_K | d_model × d_k | 查询与键的可学习投影 |
| W_V | d_model × d_v | 值的可学习投影 |
| Q、K | n × d_k | 查询和键 |
| V | n × d_v | 值 |
| QKᵀ | n × n | 各查询位置与各键位置的匹配分数 |
| A = softmax(QKᵀ / √d_k) | n × n | 对每一行沿键的位置归一化后的权重 |
| AV | n × d_v | 按注意力权重汇总的信息 |

Q 表示用于匹配的信息需求，K 表示可被匹配的特征，V 表示实际汇总的信息。这些是训练得到的向量，不是人工写出的文字问题。

对位置 i，输出为：

\[
z_i=\sum_j A_{ij}v_j
\]

注意力权重描述当前层和当前头的信息汇总方式，不能直接等同于模型完整的推理过程。

## 5. 多头、位置与前馈网络

对应 PDF 第 68–69、76 页，以及第 100–104 页。

- 多头注意力：不同头有不同的投影矩阵；各头并行计算，结果拼接后通过 W_O 投影回 d_model。
- 位置信息：基础全连接自注意力没有显式位置标记。原始 Transformer 将位置编码与 token embedding 相加。
- FFN：对各位置分别应用共享的前馈网络，通常先升维，经过非线性激活，再投影回模型维度。

注意力实现位置之间的信息交互；FFN 对每个位置的特征进行非线性变换。

补充：正弦位置编码可在新位置计算，并不保证模型能够可靠外推到任意长度；现代模型也可能使用 RoPE 等其他位置机制。

## 6. Encoder 与 Decoder

对应 PDF 第 64–72 页，以及第 105–115 页。

编码器通过自注意力和 FFN 等组件，把源序列转换为上下文表示。

解码器包含因果自注意力、交叉注意力及 FFN 等组件：

| 注意力类型 | Q 来源 | K、V 来源 | 可读取范围 |
| --- | --- | --- | --- |
| 编码器自注意力 | 编码器子层输入 | 同一子层输入 | 源序列的有效位置 |
| 解码器因果自注意力 | 解码器子层输入 | 同一子层输入 | 当前及之前的目标序列位置 |
| 编码器—解码器交叉注意力 | 解码器当前表示 | 编码器输出 | 源序列的有效位置 |

表中“来源”指投影前的隐藏表示，Q/K/V 仍需通过各层的投影矩阵计算。

解码器输出经过线性投影得到词表分数，再经 softmax 得到下一 token 的概率。选择一个 token 后继续生成，直到结束标记或其他停止条件。

补充：GPT 类模型通常使用 decoder-only 架构，没有原始翻译架构中独立的编码器及其交叉注意力。

## 7. Mask、训练与生成

对应 PDF 第 75 页及课堂末尾问答。

因果 mask 阻止位置 i 读取位置 j > i 的信息。常见做法是在 softmax 前把禁止位置的分数设为负无穷，使其权重为零。

- 训练时，完整目标文本已知。输入与预测目标错开一个位置，借助 mask，可以并行计算各位置的预测损失。
- 自回归生成时，后续 token 尚未确定，通常逐个生成。

注意力里的 softmax 对可读取位置进行归一化；输出端的 softmax 对词表进行归一化。函数相同，作用的对象和用途不同。

## 8. 其他组件

对应 PDF 第 73–78 页。

| 组件 | 作用 |
| --- | --- |
| 残差连接 | 使用 x + f(x)，保留信息路径并帮助梯度传播 |
| LayerNorm | 归一化特征，帮助稳定训练 |
| Dropout | 训练时随机丢弃部分激活等，以减少过拟合 |
| Label smoothing | 软化目标分布，减少过度确信 |

补充：常见标签平滑把部分概率分配给其他类别，并不自动识别哪些其他词在语义上也合理。不同 Transformer 变体对归一化位置和训练正则化有不同选择。
