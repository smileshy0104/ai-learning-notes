## 核心问题

Transformer 如何把 token 的初始向量，转换成结合上下文的表示，并用这些表示预测输出 token？

基本流程：

```text
文字 → token ID → token embedding + 位置信息
     → 多层注意力与前馈网络 → 隐藏表示
     → 词表上的分数 → softmax → 下一个 token 的概率
```

原始 Transformer 用编码器处理源语言，用解码器逐步生成目标语言。

## 0. 基础工具箱：十四个概念，每个配一个例子

通用机器学习基础，不属于课件章节，配套 [HTML ⓿ 基础概念](lecture-01-visual.html#basics)。每个概念按“定义 → 为什么需要 → 本例数字”组织。

**贯穿全节的例子**：词表 4 个词（可爱、柔软、阅读、是），网络把“泰迪熊”压成 h = [0.5, −0.3]，要预测下一个词，正确答案是“可爱”。

### 概念 1：张量、向量、矩阵与形状

**定义**：标量是一个数，向量是一串数，矩阵是二维表格，张量是高维推广。形状记为 (行, 列)；矩阵乘法要求左矩阵列数 = 右矩阵行数。

**例子**：h 是 (1, 2)，W 是 (2, 4)，相乘得到 (1, 4) —— 正好 4 个词各一个分数。若 W 写成 (3, 4)，就无法相乘，这就是“维度对不上”的来源。

### 概念 2：参数与超参数

**定义**：参数是训练自动更新的数字；超参数是人事先选定、训练不会改变的配置。

| 类别 | 本例中 | 真实模型中 | 谁决定 |
| --- | --- | --- | --- |
| 参数 | W 的 8 个数 | 所有权重，可达上千亿 | 训练更新 |
| 超参数 | 学习率 2、隐藏维度 2、词表 4 | 层数、d_model、头数、学习率 | 人事先选定 |

### 概念 3：前向传播

**定义**：把输入按网络顺序逐层算一遍，一直算到输出（预测值）。前向不修改任何参数，参数只在反向与更新时改变。

**为什么需要**：它定义了“模型此刻给什么预测”，损失与梯度都基于这次前向；推理时只做前向。

**例 1（多层如何串起来）**：x = [1.0, 2.0]，W₁ = [0.5, 0.3]，W₂ = 2.0：

\[
z = 1.0\times0.5+2.0\times0.3 = 1.1
\]

\[
h = \mathrm{ReLU}(1.1) = 1.1,\qquad y = 1.1\times2.0 = 2.2
\]

前向的终点是预测值 2.2；若目标为 3.0，损失 = (2.2 − 3.0)² / 2 = 0.32。

**例 2（本节的例子）**：h = [0.5, −0.3] → 线性层 z = [0.440, 0.550, −0.340, −0.030] → softmax p = [0.3125, 0.3489, 0.1433, 0.1953]。这两步合起来就是一次前向，终点是 4 个概率。

**易错点**：前向算出的中间结果（z、p）不是要学的东西，训练要学的是参数 W。换一条输入，前向流程不变，只是 h 与输出不同。

### 概念 4：线性层（全连接层）

**定义**：y = x·W + b，每个输出元素是输入与某一列的点积。

**例子**：可爱 = 0.5×1.0 + (−0.3)×0.2 = 0.440；四个词一起算得 z = [0.440, 0.550, −0.340, −0.030]。

| 词 | W 第 1 行 | W 第 2 行 | 0.5 × 第 1 行 | (−0.3) × 第 2 行 | z |
| --- | --- | --- | --- | --- | --- |
| 可爱 | 1.0 | 0.2 | 0.500 | −0.060 | 0.440 |
| 柔软 | 0.5 | −1.0 | 0.250 | 0.300 | 0.550 |
| 阅读 | −0.5 | 0.3 | −0.250 | −0.090 | −0.340 |
| 是 | 0.0 | 0.1 | 0.000 | −0.030 | −0.030 |

### 概念 5：激活函数（ReLU）

**定义**：ReLU(x) = max(0, x)，负数变 0，正数不变。

**为什么需要**：只有线性层时，多层叠加仍是线性变换（两次矩阵乘法可合并），加深没有意义。

**例子**：ReLU(1.1) = 1.1，ReLU(−0.7) = 0，ReLU(0) = 0。输出层前一般不用 ReLU，因为 logits 需要允许负数。

### 概念 6：logits 与 softmax

**定义**：模型原始输出叫 logits，可为任意实数；softmax 先取指数（放大差距、消掉负号），再除以总和，得到非负、和为 1 的概率。

| 输入 logits | softmax | 说明 |
| --- | --- | --- |
| [0, 0] | [0.500, 0.500] | 完全一样 |
| [2, 1] | [0.731, 0.269] | 差 1，领先明显 |
| [4, 1] | [0.953, 0.047] | 差 3，几乎一边倒 |

**例子**：本例先全体减最大值 0.550，再取指数：

| 词 | z | z − 0.550 | exp | p |
| --- | --- | --- | --- | --- |
| 可爱（目标） | 0.440 | −0.110 | 0.896 | 0.3125 |
| 柔软 | 0.550 | 0.000 | 1.000 | 0.3489 |
| 阅读 | −0.340 | −0.890 | 0.411 | 0.1433 |
| 是 | −0.030 | −0.580 | 0.560 | 0.1953 |

exp 之和 = 2.866。模型更倾向“柔软”（34.9%），正确答案只有 31.3%，答错了。

### 概念 7：损失函数

**定义**：把预测与目标的差距压缩成标量。回归用 MSE = (y − t)² / 2；分类与语言模型用交叉熵 L = −ln p(正确类别)。

**例子**：L = −ln 0.3125 = 1.163。参照值：p = 0.99 → 0.010；0.70 → 0.357；0.01 → 4.605。

同一组概率用 MSE 约为 0.163，但对“正确词概率偏低”不敏感、梯度小，所以语言模型用交叉熵。

### 概念 8：梯度

**定义**：损失对某参数的偏导，表示该参数增大时损失怎么变；正梯度表示增大会让损失变大。

**例子**：f(w) = w² 在 w = 3 处梯度为 6。本例中 dL/dz(可爱) = −0.6875，负数表示增大该分数能降低损失。

### 概念 9：反向传播

**定义**：用链式法则从损失逆向往回逐层求梯度，一次前向+反向即可得到所有参数的梯度。

**关键结论**：softmax + 交叉熵对 logits 的梯度 = 预测概率 − 目标。

| 词 | p | 目标 | dL/dz |
| --- | --- | --- | --- |
| 可爱 | 0.3125 | 1 | −0.6875 |
| 柔软 | 0.3489 | 0 | 0.3489 |
| 阅读 | 0.1433 | 0 | 0.1433 |
| 是 | 0.1953 | 0 | 0.1953 |

再往前一层，参数梯度 = 输入 × 上层梯度：

| 词 | 第 1 行（h₁ = 0.5） | 第 2 行（h₂ = −0.3） |
| --- | --- | --- |
| 可爱 | −0.3437 | 0.2062 |
| 柔软 | 0.1744 | −0.1047 |
| 阅读 | 0.0716 | −0.0430 |
| 是 | 0.0977 | −0.0586 |

### 概念 10：梯度下降与学习率

**定义**：W ← W − η × 梯度。η 是学习率，决定步长。

**例子**：f(w) = w²，η = 0.1：w = 3 → 2.40（f 从 9 降到 5.76）→ 1.92（f 降到 3.69）。

本例 8 个参数更新一次（η = 2）：

| 词 | W 第 1 行（旧 → 新） | W 第 2 行（旧 → 新） |
| --- | --- | --- |
| 可爱 | 1.0000 → 1.6875 | 0.2000 → −0.2125 |
| 柔软 | 0.5000 → 0.1511 | −1.0000 → −0.7907 |
| 阅读 | −0.5000 → −0.6433 | 0.3000 → 0.3860 |
| 是 | 0.0000 → −0.1953 | 0.1000 → 0.2172 |

更新后再前向：可爱 31.3% → 46.4%，L 1.163 → 0.768（−34.0%）。

### 概念 11：batch、epoch 与迭代

**定义**：batch 是一次前向+反向的样本数；迭代是一次参数更新；epoch 是把训练集完整过一遍。

**例子**：训练集 4 条样本、batch = 2 → 每 epoch 2 次迭代；batch = 4 时每 epoch 只更新 1 次。

### 概念 12：训练与推理

**定义**：训练要前向、损失、反向、更新，并保存梯度与优化器状态；推理只做前向。

| 项目 | 训练 | 推理 |
| --- | --- | --- |
| 参数 | 1× | 1× |
| 梯度 | 1× | 不需要 |
| Adam 一阶/二阶动量 | 各 1× | 不需要 |
| 合计显存 | 约 4×（混合精度约 3×） | 约 1× |
| Dropout | 开启 | 关闭 |

### 概念 13：梯度消失与梯度爆炸

**定义**：反向传播逐层连乘，因子略小于 1 则指数衰减，略大于 1 则指数增长。

**例子**：0.5¹⁰ ≈ 9.8×10⁻⁴（消失）；2¹⁰ = 1024（爆炸）；0.9¹⁰ ≈ 0.349，1.1¹⁰ ≈ 2.594。

Transformer 的三处应对：残差提供直通路径；LayerNorm 稳定尺度；注意力把任意两位置的距离变成常数级。

### 概念 14：过拟合与正则化

**定义**：过拟合指训练集表现好、新数据变差；正则化是限制“死记”的手段（Dropout、标签平滑、权重衰减）。

**例子**：训练损失 2.0 → 0.3，验证损失 2.1 → 2.6，属典型过拟合。Dropout p = 0.1：训练时每个激活值有 10% 概率置 0，推理时全部打开。

### 与 Transformer 的对应关系

| 本例 | 真实 Transformer |
| --- | --- |
| h = [0.5, −0.3]（2 维） | 最后一个位置的隐藏表示（如 4096 维），由注意力 + FFN 算出 |
| W 是 2×4 | 输出投影 d_model × V，V 可达十几万 |
| 4 个词的 softmax | 整个词表的 softmax |
| 目标“可爱” | 训练数据中真实的下一个 token |
| −ln p | 同样的交叉熵，对所有位置求平均 |

第一讲后面的结构（多头、位置编码、残差、LayerNorm）都在解决“怎样把 h 算得更好”；从 h 到概率、损失、更新，就是本节这套流程。

## 补充阅读：从 N-gram 到学习表示

这部分不是第一讲的独立课件章节，而是参考《大语言模型基础 - 大模型技术与发展》1.1–1.3 节补充的前置动机，配套 [HTML 图解](lecture-01-visual.html#background)。原文副本见 [references/llm-foundations.md](../../references/llm-foundations.md)。

语言模型的基本任务是给定前文，给下一个 token 分配概率。最简单的做法是统计同样的前文后面出现过什么。

训练小语料（分别统计，不跨句连接）：

```text
[BOS] agent learns [EOS]
[BOS] agent works [EOS]
```

Bigram 只依赖前一个词：

| 条件 | 计数 | 概率 |
| --- | --- | --- |
| P(agent \| [BOS]) | 2 / 2 | 1 |
| P(learns \| agent) | 1 / 2 | 0.5 |
| P(\[EOS\] \| learns) | 1 / 1 | 1 |

于是 P(agent learns [EOS] | [BOS]) = 1 × 0.5 × 1 = 0.5。

两个关键问题：

- **稀疏**：未见过的前文或未见过的组合计数为 0，概率估计直接失效；平滑与回退只能缓解。
- **不共享知识**：计数表知道 agent learns，却无法自然推广到 robot learns。

这正是“学习表示”的动机：把离散符号映射到可计算、可共享参数的空间。它不保证新组合都合理，但避免了只靠词组计数。

2003 年的神经语言模型（NNLM）先给每个词一张稠密向量表，再用前馈网络根据前几个词预测下一个词。没见过的组合也能得到合理概率，因为相似词共享参数。

词变成向量后，就可以用余弦相似度衡量“意思接近”：

\[
\cos(a,b)=\frac{a\cdot b}{|a|\,|b|}
\]

用第 ② 节那张示例嵌入表计算（教学数据）：泰迪熊·可爱 0.981、阅读·书 0.985、泰迪熊·阅读 −0.333、可爱·“.” −0.784。余弦只看方向，向量整体放大不会改变相似度。

第一讲的路线可以这样衔接：计数难以共享 → 学习向量；静态向量没有语境 → 序列模型；循环路径过长 → 注意力直接读取。

## Introduction：课程目标与发展脉络

对应 PDF 第 1–16 页的课程开场，以及第 17–22 页的 Introduction。配套 [HTML 导读](lecture-01-visual.html#introduction) 提供发展时间轴、展开讲解和概念对照。

### 课程要回答什么问题？

课件第 4–5 页列出两个目标：理解 Transformer 的工作方式及其与 LLM 的关系；理解 LLM 如何训练及如何应用。学习路线可以概括为架构、训练、应用。

本讲首先解决架构问题：文字怎样变成向量，不同位置怎样交换信息，以及这些计算怎样支持翻译与生成。后续课程再深入训练和应用。

课程面向研究或职业发展、个人项目及 AI 素养等不同需求。前置知识是机器学习基础与线性代数。需要逐步掌握向量、矩阵、点积、矩阵乘法、参数、损失与训练等概念，不要求在开始时就记住课件中所有缩写。

### 2010 年代：任务专用的 NLP 模型

NLP 是自然语言处理（Natural Language Processing）。课件第 18 页以三类任务举例：

- 情感分析：把评论分类为正面、负面或中性。
- 机器翻译：把源语言句子转换为目标语言句子。
- 命名实体识别：在文本中标出人名、地名等实体。

当时常见的方式是针对不同任务训练或适配模型。RNN 是重要的序列建模架构之一，能够按顺序处理文本，但训练中的顺序依赖和长距离信息传递会带来限制。后文将具体说明这些限制。

这里是课堂对发展主线的概括，不代表当时所有方法都采用 RNN，也不代表每个任务都完全无法共享知识。

### 2017 年：Transformer 架构

课件第 19 页介绍《Attention Is All You Need》。它在机器翻译背景下提出 Transformer，使用自注意力支持位置之间的信息交互，原始架构具有编码器和解码器。

课堂强调可扩展性：在合适的训练配置下，增加参数、数据与计算投入可以进一步改善能力；矩阵形式的计算也适合训练中的并行处理。这里不应理解为只要扩大规模，每项能力就必然改善，数据质量和训练方法仍然关键。

### 2022 年：对话式产品走向大众

课件第 20–21 页以 ChatGPT 发布说明交互方式的转折：用户可以通过自然语言提问、澄清、改写，并通过同一对话接口提出多种任务。

补充理解：这种能力来自架构、训练数据、规模、训练方法及产品设计等共同发展。ChatGPT 是产品名，不能与 Transformer 架构等同。

### 课件所述当下：代理系统

课件第 22 页介绍代理阶段，并以编程工具举例。用修复报错作比较：对话助手可以解释错误和给出建议；具备工具与权限的代理系统还可以读文件、修改代码、运行检查，并根据结果继续工作。

以下循环是教学补充，用于帮助理解代理概念：

```text
接收目标 → 模型决定下一步 → 外部程序执行工具
                  ↑                 ↓
                  └── 获取结果，继续或结束
```

模型负责生成决策与调用信息，外部程序负责实际执行。能力还取决于工具、上下文管理、权限和验证；拥有工具并不保证完成任务。

### 区分架构、模型、产品与系统

| 名称 | 所属层面 | 含义 |
| --- | --- | --- |
| Transformer | 架构 | 神经网络模块的连接和计算方式 |
| LLM | 模型 | 经过训练的大语言模型 |
| ChatGPT | 产品 | 对话交互入口及相关功能 |
| AI Agent | 系统 | 模型结合工具、状态与执行循环，围绕目标推进工作 |

它们可以在同一个应用中共同出现，但分别描述不同层面。

### 本讲的学习路径

课件第 17 页给出的顺序为 Introduction、Tokenization、Word representation、Self-attention mechanism、Transformer architecture、End-to-end example、Discussion。

学习时可以依次追问：文字如何切分？token 如何表示？如何读取上下文？组件如何连接？最后如何走完一次翻译？

理解检查：

1. 为什么 Transformer 架构图并不等于一个已经训练好的聊天模型？
2. ChatGPT 与 AI Agent 分别描述什么？它们能否同时出现在同一产品里？
3. 为什么先用机器翻译理解原始 Transformer，再学习现代变体？

解析：架构只规定计算设计，模型能力需要训练获得；ChatGPT 描述产品，Agent 描述围绕目标执行步骤的系统形式，两者可以结合；翻译任务能完整展示输入表示、上下文交互和逐步输出，有利于理解后续变体的组件变化。

## 1. Tokenization：文字如何成为模型输入

对应 PDF 第 24–31 页。

分词器将文字切成 token，再把 token 映射为词表中的 ID。ID 是索引，不是语义大小：编号相近不意味着意思相近。

| 方式 | 优势 | 主要代价 |
| --- | --- | --- |
| Word-level | 直观，常见文本序列较短 | 词表大，存在未登录词问题 |
| Character-level | 基础词表较小 | 序列长，计算开销增加 |
| Subword-level | 在词表大小和序列长度间折中 | 效果依赖训练语料和切分规则 |

课堂口头介绍了 BPE（Byte Pair Encoding）：从基础单元出发，反复合并语料中最常见的相邻 token 对，直到满足停止条件。它学习频繁组合，不保证每个组合都是语言学词根。

### 分词器与词表规模

课件只在第 24、27 页标出 Vocabulary 与序列长度，具体量级来自课堂问答。配套 [HTML 图解](lecture-01-visual.html#tokens) 提供可切换的 BPE 合并步骤。

分词器（tokenizer）是独立于神经网络的组件，两个阶段用途不同：

- 训练分词器：从语料统计词表与合并规则。
- 使用分词器：encode 把文字变成 ID，decode 把生成的 ID 变回文字。

词表大小 V 与序列长度 n 相互牵制。以下区间用于建立直觉，具体数值以各模型的分词器说明为准。

| 粒度 | 大致词表规模 | 序列长度 | 主要代价 |
| --- | --- | --- | --- |
| 字符级 | 几十到几百 | 最长 | 位置多，计算与长距离依赖更重 |
| 子词级（主流） | 约 3 万到 20 万 | 中等 | 依赖语料与语言覆盖 |
| 词级 | 可达数十万以上 | 最短 | 未登录词、形态变化导致词表膨胀 |

BPE 的核心机制可以用三个词演示（read ×4、reader ×2、reading ×3）：

| 步骤 | 合并 | read 的切分 | 词表 |
| --- | --- | --- | --- |
| 0 | 无 | r e a d | 7 个字母 |
| 1 | a + d → ad | r e ad | 8 |
| 2 | e + ad → ead | r ead | 9 |
| 3 | r + ead → read | read | 10 |

高频相邻符号对优先合并，词表逐步变大，同一句话的 token 数逐步变少。reader、reading 因此能复用 read 这个符号。真实 BPE 通常从字节开始，并在词边界内统计相邻对。

词表大小直接影响输入嵌入表的参数量 V × d_model。以 d_model = 4096 为例：

| V | 嵌入表参数量 | 说明 |
| --- | --- | --- |
| 32,000 | 约 1.31 亿 | 词表小，序列更长 |
| 50,257 | 约 2.06 亿 | 英文为主的常见量级 |
| 200,000 | 约 8.19 亿 | 单这一层就占很多参数 |

词表很大时，每个符号在训练中出现的次数变少，低频符号的向量难以学好，所以规模是效率、覆盖率与学习效果的折中。总计算量还取决于序列长度：注意力分数矩阵是 n × n。

多语言场景（课堂问答）：分词器在多语言语料上训练时，词表会被各语言分享。只关心单一语言时序列可能变长；跨语言共享的符号也可能带来帮助。做多语言任务应确认分词器覆盖目标语言。

### 特殊 token

对应 PDF 第 28–31 页。词表除了普通文字片段，还预留了带固定含义的特殊 token。配套 [HTML 图解](lecture-01-visual.html#tokens) 提供对照表、[UNK] 示例与填充切换。

| 特殊 token | 名称 | 作用 |
| --- | --- | --- |
| `[UNK]` | Unknown | 表示词表里没有这个片段 |
| `[BOS]` | Beginning of sequence | 标记序列开始，用于启动生成 |
| `[EOS]` | End of sequence | 标记序列结束，模型输出它时应停止 |
| `[PAD]` | Padding | 把短序列补到统一起见长度，填充位置不是真实内容 |

课件示例：假设词表只有 `teddy bear`、`cute bear`、`bear`、`[UNK]` 四项，把 `teddy bear` 误写成 `tedi bear` 时，`tedi` 不在词表中，只能分词为 `[UNK] bear`。

生成示例：输入以 `[BOS]` 开头，输出末尾应当是 `[EOS]`。前者是使用者构造的输入起点，后者是模型需要学会预测的停止信号。

填充示例：句子 A 有 7 个 token，句子 B 有 3 个，补齐到 8 个位置后两者可以堆叠为矩阵。实际训练中通常需要用注意力掩码忽略填充位置，否则这些位置会参与权重分配和损失计算。

补充：

- 不同模型使用不同写法，如 `<s>`、`<|endoftext|>`、`<|start_header_id|>`；对话模型还常出现表示说话角色的 token。使用具体模型时应查它自己的分词器说明。
- 课件未穷举所有约定。现代字节级分词器能把常见拼写片段都映射到词表项，因此普通文本很少真的产生 `[UNK]`。
- `[BOS]`/`[EOS]` 与位置编码、掩码、生成停止条件是不同层次的概念，不能混用。

常见特殊 token：`[UNK]`、`[BOS]`、`[EOS]`、`[PAD]`。名称和使用规则取决于具体模型。使用完整字节覆盖的分词器可以避免一般文本的未登录词问题，因此并非每个现代模型都依赖 `[UNK]`。

## 2. Embedding：从编号到可学习向量

对应 PDF 第 33–44 页。这一节在大纲中称为 Word representation，课件第 33 页的标题是 Token representations。配套 [HTML 图解](lecture-01-visual.html#embedding) 提供 one-hot 与嵌入表的对照。

设词表大小为 V，嵌入维度为 d，嵌入表大小为 V × d。每个 token ID 对应其中一行。

- One-hot：长度为 V，只有对应编号处为 1。不同 token 的点积恒为 0，因此无法表达“意思接近”。
- Embedding：长度为 d 的可学习向量，通常 d 远小于 V。相似性写在数字里，可用点积或余弦相似度衡量。
- 查嵌入表在数学上等价于 one-hot 行向量乘嵌入矩阵，实际实现通常直接索引，避免用几乎全零的向量做乘法。

| 对比项 | One-hot | Learned embedding |
| --- | --- | --- |
| 长度 | V（词表大小） | d（可选超参数） |
| 是否可学习 | 否，写死 | 是，训练中更新 |
| 相似度 | 任意两个都正交，恒为 0 | 可表达“意思接近” |
| 参数量 | 0（只是下标） | V × d |

Word2Vec 通过代理任务学习词向量：CBOW 用上下文预测中心词，Skip-gram 用中心词预测上下文。课件用预测下一个词演示向量学习过程，这是教学简化。

静态词向量的关键限制：同一个词的向量不会随所在句子改变，难以直接区分多义词的当前含义。

## 3. 神经网络结构：Word2vec、RNN、LSTM 与早期注意力

对应 PDF 第 34–55 页。配套 [HTML 图解](lecture-01-visual.html#neural-nets) 重绘了这三类网络结构图，并提供 Word2vec 训练前后的概率对比。

### Word2vec 的网络结构

课件第 35 页只画了三层：输入 V、隐藏层 d、输出 V。隐藏层就是最终使用的词向量，W₁ 尺寸 V × d，W₂ 尺寸 d × V。

训练的不是最终任务，而是代理任务（Skip-gram 用中心词预测上下文，CBOW 用上下文预测中心词）。课件第 36–41 页用句子 “A cute teddy bear is reading” 演示用 “A” 预测 “cute”：

| 项目 | 内容 |
| --- | --- |
| 输入 | “A” 的 one-hot，长度 V = 6 |
| 隐藏层 | d = 2 的可学习向量 |
| 输出 | 6 个概率，经 softmax 归一化 |
| 目标 | “cute” 的 one-hot |
| 损失 | 交叉熵，只关心目标项概率是否接近 1 |

训练若干次后，同一输入下 “cute” 的概率上升，隐藏向量也随之变化，这组向量就是学到的词义表示。

训练结束后只保留中间的嵌入矩阵，其余权重可以丢弃。Word2vec 因此更像“词向量算法”，而不是可用的语言模型。

原始做法要对整个词表做 softmax，词表十万级时每个预测都要算十万个分数。负采样把它改成二分类：正样本取真实相邻词对，负样本随机抽 5～15 个不相关词，让模型判断“是否相邻”。这样不必遍历词表，代价是优化的是近似目标。

| 方法 | 核心做法 | 主要优势 | 主要局限 |
| --- | --- | --- | --- |
| Word2Vec（2013） | 浅层网络做预测：CBOW 由上下文猜中心词，Skip-gram 由中心词猜上下文 | 简单、快，词向量成为独立产品 | 静态；只利用局部窗口 |
| GloVe（2014） | 统计全局共现矩阵并分解，让点积接近共现次数对数 | 利用全局统计 | 静态；需预先统计 |
| FastText（2016） | 词拆成字符 n-gram，词向量为子词向量之和 | 能拼出未见词，抗拼写变体 | 存储开销大 |

三者共同边界：一个词只有一个向量，与所在句子无关。把向量从“查出来”变成“算出来”，是 ELMo／BERT／GPT 的起点。

### RNN 与任务形式### RNN 与任务形式

RNN 用隐藏状态概括已处理的序列：

\[
h_t=f(h_{t-1},x_t)
\]

课件第 51 页列出 RNN 可承担的任务：生成（文本→文本）、分类（文本→一个类别）、多分类（每个位置一个标签）、情感分析、翻译、命名实体识别。

两个限制：长距离信息要经过多次状态更新，容易被稀释；时间步之间存在依赖，无法并行训练。

### LSTM

LSTM（1997）保留隐藏状态，另加细胞状态，用遗忘门、输入门、输出门控制信息的保留与写入。它缓解长距离依赖，但仍是顺序计算，也没有彻底解决问题。

### 早期注意力（2014）

Bahdanau 等人的工作让解码器在生成每个词时直接读取源句的相关位置。例如生成法语 “lit” 时把注意力指向源句的 “reading”，而不是只靠编码器最后那个状态向量。

这里的注意力连接解码器与编码器，是 cross-attention 的前身；Transformer 的关键变化是把注意力用于同一序列内部（self-attention），并去掉循环结构。

## 4. Self-attention：Q、K、V

对应 PDF 第 57–62 页，以及第 91–101 页的展开示例。

以下公式是结合课程内容给出的标准数学整理，图中符号尚需视觉核对。

设输入 X 的形状为 n × d_model，其中 n 是序列长度。对于单个注意力头：

\[
Q=XW_Q,\quad K=XW_K,\quad V=XW_V
\]

\[
\operatorname{Attention}(Q,K,V)
=\operatorname{softmax}\left(\frac{QK^\top}{\sqrt{d_k}}\right)V
\]

| 对象 | 形状 | 含义 |
| --- | --- | --- |
| X | n × d_model | 每行对应一个位置的输入表示 |
| W_Q、W_K | d_model × d_k | 查询与键的可学习投影 |
| W_V | d_model × d_v | 值的可学习投影 |
| Q、K | n × d_k | 查询和键 |
| V | n × d_v | 值 |
| QKᵀ | n × n | 各查询位置与各键位置的匹配分数 |
| A = softmax(QKᵀ / √d_k) | n × n | 对每一行沿键的位置归一化后的权重 |
| AV | n × d_v | 按注意力权重汇总的信息 |

Q 表示用于匹配的信息需求，K 表示可被匹配的特征，V 表示实际汇总的信息。这些是训练得到的向量，不是人工写出的文字问题。

对位置 i，输出为：

\[
z_i=\sum_j A_{ij}v_j
\]

一个更接近真实任务的直觉是指代消解：“The animal didn't cross the street because it was too tired.” 处理 it 时，注意力可以把绝大部分权重放在 animal 上（示意分布：animal 0.982、tired 0.012、it 0.002、其余合计约 0.004）。这些权重来自训练，不是人工规则。但高权重只说明信息流向，不等于因果解释。

注意力权重描述当前层和当前头的信息汇总方式，不能直接等同于模型完整的推理过程。

### 手算一遍（5 个位置，d_k = 3）

配套 [HTML 图解](lecture-01-visual.html#attention) 可以切换不同查询向量观察权重的变化。下面固定第 5 个位置“阅读”作为查询，序列为“泰迪熊 / 可爱 / 阅读 / 是 / 现在分词”。

第一步，直接给定 K 与 V（真实模型中它们由 X 分别乘 W_K、W_V 得到）：

| 位置 | K | V |
| --- | --- | --- |
| 泰迪熊 | [1, 1, 0] | [0.6, 0.2, 0.1] |
| 可爱 | [1, 0, 1] | [0.5, 0.1, 0.3] |
| 阅读 | [0, 1, 1] | [0.1, 0.7, 0.4] |
| 是 | [1, 1, 1] | [0.2, 0.2, 0.2] |
| 现在分词 | [0, 0, 1] | [0.1, 0.3, 0.8] |

查询 q = [1, 0, 1]。

第二步，点积并缩放：

| 位置 | q · k | 除以 √3 ≈ 1.732 |
| --- | --- | --- |
| 泰迪熊 | 1.000 | 0.577 |
| 可爱 | 2.000 | 1.155 |
| 阅读 | 1.000 | 0.577 |
| 是 | 2.000 | 1.155 |
| 现在分词 | 1.000 | 0.577 |

第三步，softmax（先减去最大值 1.155 再取指数，结果不变但数值更稳定）：

| 位置 | 缩放后 − 最大值 | exp | 权重 |
| --- | --- | --- | --- |
| 泰迪熊 | -0.577 | 0.561 | 0.152 |
| 可爱 | 0.000 | 1.000 | 0.271 |
| 阅读 | -0.577 | 0.561 | 0.152 |
| 是 | 0.000 | 1.000 | 0.271 |
| 现在分词 | -0.577 | 0.561 | 0.152 |

权重之和为 1.000。分数只有两档，所以权重也只有两种取值。

第四步，按权重加权求和 V：

```text
0.152×[0.6, 0.2, 0.1] + 0.271×[0.5, 0.1, 0.3] + 0.152×[0.1, 0.7, 0.4] + 0.271×[0.2, 0.2, 0.2] + 0.152×[0.1, 0.3, 0.8]

第 1 维：0.091 + 0.136 + 0.015 + 0.054 + 0.015 = 0.312
第 2 维：0.030 + 0.027 + 0.107 + 0.054 + 0.046 = 0.264
第 3 维：0.015 + 0.081 + 0.061 + 0.054 + 0.122 = 0.334
```

所以该位置的输出约为 [0.312, 0.264, 0.334]。它不是“阅读”自己的值 [0.1, 0.7, 0.4]，而是按权重混合了整句的信息。


要注意这个例子的局限：

- 真实 K、V 由可学习投影得到，分数常为负数，权重分布可能非常悬殊。
- 这里的 q 直接给定，真实模型会从输入现场计算。
- 权重反映信息路由，不等于模型决策的因果解释。

## 4.5 其他组件：位置、多头、FFN、残差与归一化

对应 PDF 第 68–78、100–104 页。配套 [HTML 图解](lecture-01-visual.html#components) 提供位置相加、FFN 数值、残差与 LayerNorm 的示意。

### 位置信息

基础全连接自注意力对重排具有置换等变性：只交换输入顺序，输出会跟着交换，网络本身不知道“谁在第几个位置”。

原始 Transformer 把位置编码与 token embedding 逐项相加，两者同维：

\[
PE(pos,2i)=\sin\left(\frac{pos}{10000^{2i/d_{model}}}\right),\quad
PE(pos,2i+1)=\cos\left(\frac{pos}{10000^{2i/d_{model}}}\right)
\]

- 不同维度对应不同频率，组合后可以区分不同位置。
- 数学上能计算训练长度以外位置的编码，但不保证模型能可靠外推到任意长度。
- 编码差并不只由相对距离决定；后续相对位置方法（如 RoPE）主要解决的是另一类问题。

### 多头注意力

设 d_model = 512，h = 8，每头 d_v = 64：拼接后是 8 × 64 = 512 维，再乘 W_O 回到 d_model。

不同头的投影可以学到不同的信息交互模式，但没有预设“第 1 头管语法、第 2 头管指代”。单个头同样可以表达多种关系。

### FFN（逐位置前馈网络）

\[
FFN(x)=\mathrm{ReLU}(xW_1+b_1)W_2+b_2
\]

示例（d_model = 2，d_ff = 4，偏置取 0）：

- x = [1, −1]
- xW₁ = [1, −1, 0, −2]，ReLU 后 [1, 0, 0, 0]
- 乘 W₂ 后得到 [1, 2]

各位置共享同一套 FFN 权重，因此可以批量并行计算。去掉中间的非线性后，两次线性变换可合并，网络就少了这一层带来的表达能力。

标准配置下（d_ff = 4d，Q/K/V 合计宽度 d），注意力约 4d²、FFN 约 8d²，FFN 占这两部分约 2/3。这个比例不适用于所有总参数统计，GQA、交叉注意力、门控 FFN、MoE 都会改变它。

### 残差连接

\[
y=x+f(x)
\]

输入有一条绕过子层的通道，与原输出相加。它帮助深层网络传递信息与梯度，但不能保证任何配置下都不发生梯度问题。

### LayerNorm

对每个位置的特征维度归一化：

\[
\mathrm{LN}(x)=\gamma\cdot\frac{x-\mu}{\sqrt{\sigma^2+\varepsilon}}+\beta
\]

示例：[1, 3] 的均值为 2、方差为 1，归一化后约为 [−1, 1]。由于 ε 与可学习的 γ、β，输出不必严格均值为 0、方差为 1。

| 排列 | 公式（省略 Dropout） | 说明 |
| --- | --- | --- |
| Post-Norm（原始） | LayerNorm(x + f(x)) | 先相加再归一化 |
| Pre-Norm（现代常见） | x + f(LayerNorm(x)) | 先归一化再送入子层 |

### 参数量估算

设 d_model = d，忽略偏置，标准配置（Q/K/V 合计宽度 d，FFN 中间层 4d）：

| 组件 | 构成 | 参数量 |
| --- | --- | --- |
| 自注意力 | W_Q、W_K、W_V、W_O | 4d² |
| FFN | d → 4d → d | 8d² |
| 单块合计 | — | 约 12d² |

用 GPT-3 的公开配置验证（d = 12288，96 层，词表 50257）：每层约 1.81B，96 层约 173.9B，词嵌入约 0.62B，合计约 174.6B ≈ 175B。

这个比例只适用于该配置；交叉注意力、GQA/MQA、门控 FFN、MoE 都会改变它。

## 4.6 Dropout 与标签平滑

对应 PDF 第 77–78 页。残差连接与 LayerNorm 见 4.5 节。

| 组件 | 作用 | 注意 |
| --- | --- | --- |
| Dropout | 训练时随机丢弃部分激活或连接，减少过度依赖某些特征 | 只在训练时启用，推理时关闭 |
| Label smoothing | 把目标分布软化，减少过度确信 | 常见做法是按比例把概率分给其他类别，并不识别哪些词在语义上更合理 |

两者都作用于“让模型别过度自信/别死记”，与 0 节讲的损失函数配合使用。

## 5. Encoder 与 Decoder

对应 PDF 第 64–72 页，以及第 105–115 页。

编码器通过自注意力和 FFN 等组件，把源序列转换为上下文表示。

解码器包含因果自注意力、交叉注意力及 FFN 等组件：

| 注意力类型 | Q 来源 | K、V 来源 | 可读取范围 |
| --- | --- | --- | --- |
| 编码器自注意力 | 编码器子层输入 | 同一子层输入 | 源序列的有效位置 |
| 解码器因果自注意力 | 解码器子层输入 | 同一子层输入 | 当前及之前的目标序列位置 |
| 编码器—解码器交叉注意力 | 解码器当前表示 | 编码器输出 | 源序列的有效位置 |

表中“来源”指投影前的隐藏表示，Q/K/V 仍需通过各层的投影矩阵计算。

解码器输出经过线性投影得到词表分数，再经 softmax 得到下一 token 的概率。选择一个 token 后继续生成，直到结束标记或其他停止条件。

补充：GPT 类模型通常使用 decoder-only 架构，没有原始翻译架构中独立的编码器及其交叉注意力。

## 6. Mask、训练与生成

对应 PDF 第 75 页及课堂末尾问答。

因果 mask 阻止位置 i 读取位置 j > i 的信息。常见做法是在 softmax 前把禁止位置的分数设为负无穷，使其权重为零。

- 训练时，完整目标文本已知。输入与预测目标错开一个位置，借助 mask，可以并行计算各位置的预测损失。
- 自回归生成时，后续 token 尚未确定，通常逐个生成。

注意力里的 softmax 对可读取位置进行归一化；输出端的 softmax 对词表进行归一化。函数相同，作用的对象和用途不同。

## 7. 训练、规模与现代架构（补充）

对应 HTML 的 [⑥ 深入补充](lecture-01-visual.html#deep-dive)，内容不属于第一讲课件。

训练循环、损失函数、反向传播与梯度消失已在 [0. 基础工具箱](#0-基础工具箱参数损失前向反向梯度) 中展开，这里不再重复。

### 三代范式

| 阶段 | 做法 | 数据量 | 换任务时 |
| --- | --- | --- | --- |
| 预训练 | 海量无标注文本上的自监督目标 | 极大 | 先得到基座 |
| 微调 | 用少量标注数据更新部分参数 | 几千到几万条 | 需重新训练并另存权重 |
| 提示 | 不改参数，把任务写进上下文 | 0 到几个示例 | 改几行文字 |

### 规模与缩放法则

损失随参数量、数据量、计算量增加而按幂律下降，收益递减。Chinchilla（2022）的经验结论：给定计算预算，模型与数据应同步放大，常见比例为每个参数约 20 个 token（70B 参数配约 1.4T token）。

“涌现能力”是流行说法，但也有研究认为可能是评测指标不连续造成的错觉，宜作为规划参考而非定律。

### 现代架构的改动

| 部件 | 原始（2017） | 现代常见做法 |
| --- | --- | --- |
| 整体结构 | 编码器 + 解码器 | 多为 decoder-only |
| 归一化位置 | Post-Norm | Pre-Norm |
| 归一化方法 | LayerNorm | RMSNorm 等 |
| 位置编码 | 正弦／余弦 | RoPE 等 |
| 激活函数 | ReLU | SwiGLU 等 |
| 注意力 | 标准多头 | GQA／MQA |
| FFN | 稠密 | MoE |

KV Cache 在生成时缓存已算过的 K、V，新 token 只算增量；它不改变数学输出，只改变计算与显存开销。

## 补充展望：从第一讲到今天的大模型

参考《大语言模型基础》第 1.5、2.3 节的整理，配套 [HTML 图解](lecture-01-visual.html#beyond-lecture)。

| 架构 | 主要信息路径 | 常见用途与例子 |
| --- | --- | --- |
| Encoder-only | 输入位置可双向交互 | BERT 类：表示学习、分类、检索 |
| Decoder-only | 读取前文，因果预测后续 token | GPT 类：续写、对话，也能用生成方式回答理解类任务 |
| Encoder–Decoder | 编码源输入，解码器交叉注意力读取 | T5、原始 Transformer：翻译、摘要 |

三点提醒：

- 架构差异描述的是结构，不是能力排名。
- Decoder-only 同样会处理和理解输入；标准 BERT 不采用 GPT 式自回归生成，但“编码器绝不可能用于生成”的说法过于绝对。
- 第一讲只解决“网络怎样计算”。预训练、指令训练、偏好优化、KV Cache、RoPE、GQA、Agent 工程属于后续专题。
