0. 十四个基础概念，每个配一个例子

这一节按同一套格式组织：先给定义，再说为什么需要，最后用本例数字算一遍。所有例子都来自同一个任务：词表 4 个词（可爱、柔软、阅读、是），网络把“泰迪熊”压成 h = [0.5, −0.3]，要预测下一个词，正确答案是“可爱”。

h = [0.5, −0.3]→ 线性层 →4 个分数 z→ softmax →4 个概率 p→ 交叉熵 →损失 L→ 反向 →梯度→ 更新 →新的 W

概念 1：张量、向量、矩阵与形状

定义：标量是一个数，向量是一串数，矩阵是数的二维表格，张量是它们的高维推广。形状就是每一维有多少个数，写作 (行, 列)。矩阵乘法要求左矩阵的列数等于右矩阵的行数。

为什么需要：神经网络的所有运算都是这些形状之间的乘法。看懂形状，才能判断“这一步到底算了什么、结果应该多大”。

例子：h 是形状 (1, 2) 的行向量，W 是 (2, 4) 的矩阵
(1, 2) × (2, 4) → (1, 4)：得到 4 个分数，正好对应 4 个词
如果 W 写成 (3, 4)，就没法和 h 相乘——这就是“维度对不上”的报错来源

概念 2：参数与超参数

定义：参数是训练过程中会被自动更新的数字（权重、偏置）。超参数是由人预先选定的配置，训练不会改变它。

为什么需要：分不清这两者，就不知道“该调什么”和“模型会自己学什么”。

类别本例中真实模型中谁决定
参数W 的 8 个数所有权重矩阵，可达上千亿个训练自动更新
超参数学习率 η = 2、隐藏维度 2、词表大小 4层数、d_model、头数、学习率人事先选定

概念 3：前向传播

定义：把输入按网络顺序逐层算一遍、一直算到输出（预测值）的过程。前向不修改任何参数——参数只在反向与更新时才改变。

为什么需要：它定义了“模型此刻给出什么预测”，损失与梯度都基于这一次前向的结果；推理时更是只做前向。

例 1（多层怎么连起来）：一个两层小网络，输入 x = [1.0, 2.0]，隐藏层权重 W₁ = [0.5, 0.3]，输出权重 W₂ = 2.0：

第 1 层：z = 1.0×0.5 + 2.0×0.3 = 1.1
激活：h = ReLU(1.1) = 1.1
第 2 层：y = 1.1 × 2.0 = 2.2　← 前向的终点：一个预测值
（若目标是 3.0，损失 = (2.2−3.0)²/2 = 0.32，见概念 7）

例 2（本节的例子）：h = [0.5, −0.3] 经线性层得到 z = [0.440, 0.550, −0.340, −0.030]，再经 softmax 得到 p = [0.3125, 0.3489, 0.1433, 0.1953]。这两步合起来就是一次前向，终点是 4 个概率。

h→ 线性层（概念 4）→z→ softmax（概念 6）→p→ 取 p(可爱) →损失（概念 7）

易错点：前向里也会“算”，但算出的中间结果（z、p）不是训练要学的东西；要学的是参数 W。换成另一条输入，前向流程完全一样，只是 h 不同、输出不同。

概念 4：线性层（全连接层）

定义：把输入向量乘一个权重矩阵（再加偏置），得到输出向量：y = x·W + b。每个输出元素都是“输入与某一列的点积”。

为什么需要：它是网络里唯一“带可学习参数”的基本运算，注意力的 Q/K/V 投影、FFN 的两个线性层，本质都是它。

例子（算“可爱”这一列）：0.5×1.0 + (−0.3)×0.2 = 0.500 − 0.060 = 0.440
四个词一起算，就是 h 乘整个 W：z = [0.440, 0.550, −0.340, −0.030]

概念 5：激活函数（以 ReLU 为例）

定义：紧接在线性层后面的非线性函数。ReLU(x) = max(0, x)：负数变 0，正数不变。

为什么需要：如果只有线性层，多层叠加仍是线性变换（两次矩阵乘法可以合并成一次），网络再深也表达不了复杂关系。非线性才让“加深”有意义。

例子：ReLU(1.1) = 1.1　ReLU(−0.7) = 0　ReLU(0) = 0
本例中 z 的负值（−0.340、−0.030）如果经过 ReLU 就会变成 0；但输出层前通常不用 ReLU，因为分数需要允许负数

概念 6：logits 与 softmax

定义：模型直接输出的原始分数叫 logits，可以是任意实数。softmax 把它们变成非负、总和为 1 的概率：先取指数（放大差距、消掉负号），再除以总和。

为什么需要：只有变成概率，才能解释成“下一个词是它的可能性”，也才能和交叉熵配合。

[2, 1][0.731, 0.269]差 1，领先明显
[4, 1][0.953, 0.047]差 3，几乎一边倒

差距被指数放大：logit 只差 1，概率就能差近 3 倍。

概念 7：损失函数

定义：把“预测与目标的差距”压缩成一个标量，训练才知道往哪改。回归常用均方误差 MSE = (y − t)² / 2；分类与语言模型常用交叉熵 L = −ln p(正确类别)。

为什么需要：没有标量损失就没有统一方向；不同损失对应不同任务，选错了模型会优化错误的目标。

本例的交叉熵：L = −ln 0.3125 = 1.163
正确词的概率交叉熵 L含义
0.990.010几乎确定，几乎不罚
0.700.357不错
0.31（本例）1.163明显不对
0.014.605自信地答错，重罚

把目标看成 one-hot [1,0,0,0]，MSE = 0.163。数值更小，但它衡量的是“数差多少”，对“正确词概率偏低”不敏感，梯度也小，学习会慢。交叉熵直接盯着正确词的概率，配合 softmax 还有极简的梯度形式（见概念 7）。

概念 8：梯度

定义：损失对某个参数的偏导数，表示“这个参数增大一点点，损失会怎么变”。梯度是所有这些偏导组成的向量。正梯度→该参数增大会让损失变大；负梯度→增大会让损失变小。

为什么需要：它是唯一告诉你“往哪个方向改、改多少”的量。没有梯度，训练就只能是瞎猜。

单变量例子：f(w) = w²，在 w = 3 处的梯度 = 2w = 6
意思是：w 稍微增大，f 会以约 6 倍的速率上升
本例中：dL/dz(可爱) = -0.6875，负数 → 增大这个分数能降低损失

概念 9：反向传播

定义：用链式法则，从损失出发、逆着网络方向逐层求梯度的算法。因为要先知道输出层怎么调，才能推出上一层怎么调。

为什么需要：参数成千上万，不可能逐个试。一次反向传播就能同时得到所有参数的梯度，这是训练可行的关键。

本例最值得记住的结论：softmax 与交叉熵组合后，对 logits 的梯度恰好是“预测概率 − 目标”：

概念 10：梯度下降与学习率

定义：按“负梯度方向”更新参数：W ← W − η × 梯度。学习率 η 决定每步走多远。

为什么需要：梯度只给方向，η 给步长。步长太大越过最优点，太小几乎不动。

单变量例子（f(w) = w²，η = 0.1）：
w = 3 → 梯度 6 → w = 3 − 0.6 = 2.40（f 从 9 降到 5.76）
再一步：梯度 4.8 → w = 1.92（f 降到 3.69）

概念 11：batch、epoch 与迭代

定义：batch 是一次前向+反向所用的样本数；迭代（step）是更新一次参数；epoch 是把整个训练集完整过一遍。

为什么需要：一次用全部数据太慢且占显存，一次只用一条又太抖。batch 是在速度与稳定之间的折中。

例子：训练集有 4 条样本，batch = 2
→ 每个 epoch 有 2 次迭代（2 次参数更新）
本例的“更新一次”就等于 1 次迭代；batch = 4 时，一个 epoch 只更新 1 次

概念 12：训练与推理

定义：训练要前向、算损失、反向、更新，并保存梯度与优化器状态；推理只做前向，参数冻结。

为什么需要：两者开销差好几倍，部署时要按推理算显存和延迟；一些层（Dropout）只在训练时生效。

概念 13：梯度消失与梯度爆炸

定义：反向传播是逐层连乘。若每层因子略小于 1，乘积随层数指数衰减（消失）；略大于 1 则指数增长（爆炸）。

为什么需要：它解释了“为什么加深层数反而变差”“为什么 RNN 记不住早期信息”，也解释了残差与归一化为什么必须存在。

每层因子 0.5，10 层：0.5¹⁰ ≈ 9.8×10⁻⁴　→ 底层几乎收不到梯度
每层因子 2.0，10 层：2¹⁰ = 1024　→ 参数被推飞
接近 1 也危险：0.9¹⁰ ≈ 0.349，1.1¹⁰ ≈ 2.594
梯度消失
越靠近输入的层越学不动；表现为“加深反而变差”。
梯度爆炸
损失变 NaN、数值爆掉；常用梯度裁剪。

Transformer 的三处应对（都能在后面章节对上）：残差的 1 + f′(x) 提供直通路径；LayerNorm 稳定每层尺度；注意力把任意两位置的距离变成常数级。

概念 14：过拟合与正则化

定义：过拟合指模型在训练数据上表现很好、在新数据上变差；正则化是限制模型“死记”的手段，例如 Dropout、标签平滑、权重衰减。

为什么需要：语言模型参数量远大于样本量，不加以约束很容易记住训练文本的细节。

例子：训练损失从 2.0 一路降到 0.3，验证损失却从 2.1 升到 2.6 → 典型过拟合
Dropout p = 0.1：训练时每个激活值有 10% 概率被置 0；推理时全部打开并按比例缩放

Lecture outline · Introduction（课件第 1–22 页）

Introduction：我们为什么要学 Transformer？

先把计算细节放一放。这部分帮助我们回答三个问题：这门课准备讲什么？今天的语言模型从哪里来？Transformer 在其中处于什么位置？

1. 这门课的目标：理解原理，也理解使用方式

课件提出两个目标：理解 Transformer 怎样工作、与大语言模型有什么关系；理解大语言模型怎样训练，以及怎样用于不同应用。可以把课程理解成从“模型内部怎样计算”，逐步走到“怎样把模型用在实际系统中”。

架构：信息怎样流动→训练：参数怎样学到→应用：怎样完成任务

例如，一个助手回答问题时，我们可以分别追问：它怎样读取输入？这些能力怎样通过训练获得？它什么时候需要搜索或调用工具？这些分别涉及架构、训练和应用。本讲主要打下架构基础。

2. 哪些基础会用到？

课件面向研究与职业发展、个人项目，以及希望了解 AI 的学习者，列出的前提是机器学习基础和线性代数。学习时可以按需补上：

线性代数
向量：一组数字
矩阵：按行列排列的数字
点积：两个向量逐项相乘后求和
矩阵乘法：同时计算多组组合
机器学习
参数：训练时调整的数字
预测：模型根据输入给出结果
损失：衡量预测与目标的差距
训练：根据损失调整参数

上面是帮助入门的简述。遇到具体计算时，我们再给出定义和例子；目前无需记住所有缩写。

3. 四个阶段：从专门的 NLP 模型到代理系统

NLP 是 Natural Language Processing，即自然语言处理，研究怎样让计算机处理人类语言。点击各阶段，查看它解决了什么问题。时间轴对应课件的组织方式，阶段之间存在重叠。

2010 年代 · 专门任务→2017 · Transformer→2022 · 对话→课件所述当下 · 代理
2010 年代：不同任务，常常使用不同模型

早期常见的做法，是为每种任务训练或适配专门的模型。例如：

  • 情感分析：输入“这家餐厅很好吃”，输出“正面”。
  • 机器翻译：输入一句英文，输出对应法文。
  • 命名实体识别：在“张三住在北京”中标出人名“张三”和地名“北京”。
评论 → 情感模型 → 类别英文 → 翻译模型 → 法文句子 → 实体模型 → 标注

当时 RNN 是重要的序列建模方法之一。后文会介绍它怎样通过隐藏状态传递信息，以及为什么长距离依赖和顺序计算会带来困难。这里是发展主线的简化，并不意味着当时只有 RNN。

2017 年：Transformer 提供可扩展的架构基础

《Attention Is All You Need》提出 Transformer。原始任务是机器翻译，架构由编码器和解码器组成，关键机制是自注意力：每个位置可以直接从允许访问的其他位置汇总信息。

“可扩展”可以先理解为：在合适的训练方案下，增加数据、模型参数与计算投入，可以继续改善能力。Transformer 的矩阵计算形式也适合训练中的并行处理。更多投入并不保证每项能力都自动提高，数据质量与训练设计同样重要。

Transformer 是架构；LLM 是大语言模型。可以把架构理解为“计算模块怎样连接的设计”。训练把参数学出来。现代大语言模型通常采用 Transformer 的变体，但只给出架构图，还没有得到一个能聊天的模型。
2022 年：ChatGPT 让对话式交互走向大众

课件把 ChatGPT 的发布作为产品与交互方式上的转折点。用户可以直接用自然语言提问、补充条件、要求改写，在同一对话中完成多种任务。

多种任务可以通过同一个语言模型接口表达。这依赖模型规模、训练数据与训练方法等多方面发展；对话产品也可能连接额外的模型和工具。Transformer 架构本身并不能单独解释全部对话能力。

代理阶段：从给出建议，到调用工具并根据结果继续工作

以“修复一个报错”为例：对话助手可以解释错误、给出修改建议；具备相应工具和权限的代理系统，还可以读取文件、修改代码、运行检查，再根据报错继续调整。

接收目标→模型选择下一步→系统执行工具→结果返回模型，继续或结束

这里的 Agent 可以先理解成“模型与工具、状态管理、执行循环等组成的系统”。工具由外部程序执行，模型根据获得的结果决定后续动作。能调用工具不等于一定能正确完成任务，实际能力还取决于工具、上下文、权限与验证。

前置动机：从“数出现次数”到“学习表示”

语言模型的一个基本任务是：给定前文，为下一个 token 分配概率。最直接的办法，就是统计同样的前文后面出现过什么。

训练小语料（两句话，分别统计，不跨句连接）：
[BOS] agent learns [EOS]
[BOS] agent works [EOS]
前文：agent→ 数后继词 →learns：1 次 → 1/2works：1 次 → 1/2

这叫 Bigram：只看前一个词。一般 N-gram 只看前 n−1 个词，用局部历史近似完整历史。这里的 n 是 N-gram 阶数，与后文表示序列长度的 n 属于不同语境。

P(下一个词 | 当前词) = 两词相邻出现次数 / 当前词作为前文的次数
P(agent | [BOS]) = 2/2 = 1
P(learns | agent) = 1/2
P([EOS] | learns) = 1/1 = 1
P(agent learns [EOS] | [BOS]) = 1 × 1/2 × 1 = 1/2
问题一：没见过的组合怎么办？
若 robot 在训练语料里没出现，分母计数为 0，无法直接给出概率估计；即使见过 robot，新组合 robot learns 也可能计数为 0。平滑与回退能缓解，但需要额外规则。
问题二：相似词不能自然共享知识
agent learns 出现过，不等于计数表就知道 robot learns 也合理。神经模型通过学习表示与共享参数，获得更多泛化机会。

学习向量的动机因此很具体：把离散符号映射到能计算、能共享统计规律的空间。它不保证每个新组合都合理，但能避免只靠独立的词组计数。

从“学表示”到“用表示计算相似”

2003 年的神经语言模型（NNLM）把两件事合在一起：先给每个词一张稠密向量表，再用前馈网络根据前几个词预测下一个词。收益很直接：没见过的组合也能得到一个合理的概率，因为相似词共享相近的参数。

离散词 → 查表得到稠密向量→拼接前 n−1 个词的向量→前馈网络→词表上的概率

一旦词变成了向量，“意思接近”就能用数字衡量。常用余弦相似度，它只看方向、不看长度：

cos(a, b) = (a · b) / (|a| × |b|)
1 → 方向相同；0 → 正交；−1 → 方向相反

用本页第 ② 节的示例嵌入表算一下（这些数字是教学示例，不是真实模型输出）：

词对余弦相似度怎么读
泰迪熊 · 可爱0.981方向几乎一致，意思接近
阅读 · 书0.985同为“阅读类”语境
泰迪熊 · 阅读−0.333方向偏反，关系疏远
可爱 · “.”−0.784符号类 token 与语义词差距大
余弦只看方向。若把某个向量整体放大两倍，它与别的词的余弦相似度不变，但欧氏距离会变。这也是为什么相似度常优先用余弦。

Lecture outline · Tokenization（课件第 24–31 页）

① 先把文字切成小块

模型不能直接把一段文字拿去做矩阵乘法。第一步是把文字切成 token（词元），然后给每个 token 一个编号。token 可以是完整单词、单词的一部分或标点。

原文：A cute teddy bear is reading.
Acuteteddybearisreading.

序列长度：7 个 token。完整单词各占一个 token，标点单独处理。实际词级系统还要规定大小写、数字和未知词的处理方式。

Acuteteddybearisreading.

序列长度：9 个 token。示意：teddy 拆成 ted + dy，reading 拆成 read + ing。同一小块会在不同单词之间复用，于是词表不必列出所有完整单词。

A␠cute␠teddy␠bear␠is␠reading.

序列长度：29 个 token。␠ 表示空格。基础符号很少，任何句子都能拼出来，但同一句话占用的位置变多，计算也随之增加。

观察两个量：词表大小是“总共有多少种可用的小块”；序列长度是“这句话用了多少个小块”。这里能直接看到的是后者。

三种切法仅用于比较。真实 BPE 的切分由词表与合并规则决定，空格也有具体的编码方式；这里的“按子词”不执行 BPE 训练。

想一想：为什么不把每个句子都当成一个 token？

可能出现的句子太多，有限词表无法列举。把文本切成可重复使用的小块，能用有限词表组合出大量表达。另一端，如果切得非常细，序列会变长，计算也会增加。

特殊 token：不是普通文字，却有固定作用

词表里除了普通文字块，还预留了一些带固定含义的特殊 token（special token）。它们像句子里的“功能标记”，告诉模型这段内容从哪里开始、到哪里结束，或者某个位置其实没有内容。

特殊 token名称作用例子
[UNK]Unknown，未知词表示词表里没有这个片段拼错的词被替换为 [UNK]
[BOS]Beginning of sequence，序列开始告诉模型“从这里开始”生成时先输入 [BOS]
[EOS]End of sequence，序列结束告诉模型“这里结束了”模型输出 [EOS] 时停止生成
[PAD]Padding，填充把短句补到统一起见长度，其位置不参与实际内容把 4 个 token 的句子补齐到 8 个

例 1：词表里没有的词

假设词表只有四个 token：teddy bear、cute bear、bear、[UNK]。输入写成了 tedi bear（少了一个 d），前两个字符组合不在词表里，于是：

tedi→ 词表里找不到 →[UNK]+bear

这样模型至少知道“这里有个东西，但我不认识”，而不是直接丢弃。现代使用字节级子词的分词器能让常见文字片段都落在词表内，所以遇到普通拼写错误时往往不需要 [UNK]。

例 2：开始与结束

生成文本时，需要告诉模型从哪里开始，也需要模型告诉我们何时停下：

[BOS]Whatacuteteddy bear![EOS]

[BOS] 是输入的第一个位置，用来启动生成；[EOS] 是模型应当输出的结束信号。两者不是同一件事。

例 3：为什么需要填充

同一批数据里句子长短不一。硬件喜欢整齐的矩阵，所以常把短句补齐到相同长度。下面切换看一下：

[BOS]Whatacuteteddy bear![EOS]

句子 A：7 个位置；句子 B：4 个位置。长度不同，无法直接堆成一个整齐矩阵。

句子 A（7 个）：

[BOS]Whatacuteteddy bear![EOS][PAD]

句子 B（4 个）：

[BOS]Goodnight[EOS][PAD][PAD][PAD][PAD]

两行现在都是 8 个位置，可以堆成一个整齐的矩阵。填充位置不是真实内容，训练时通常需要让注意力忽略它们，否则会干扰计算与损失。

名字不是固定的。不同模型使用不同写法，例如 <s>、<|endoftext|>、<|start_header_id|> 等；对话模型还可能出现标记“谁在说话”的角色 token（如 user、assistant）。使用一个模型时，应当查它自己的分词器说明，而不是套用这里的名字。
理解检查：[BOS] 与 [EOS] 分别由谁产生？

[BOS] 通常由使用者在构造输入时加上，作为生成起点（输入侧）；[EOS] 通常由模型在输出层预测得到，作为停止信号（输出侧）。原始 Transformer 翻译示例里，解码器输入以 [BOS] 开头，训练目标末尾则是 [EOS]。

分词器与词表规模

分词器（tokenizer）是一个独立于神经网络的组件，负责“文字 ⇄ 编号”的转换：

训练阶段：从语料统计出词表与合并规则→使用阶段：encode 文字→ID→模型计算→decode 生成 ID→文字

词表大小 V 就是“总共准备多少个可用符号”。它和序列长度 n 是一对相互牵制的量：切得越细，词表越小，但同样的句子需要更多位置；切得越粗，序列变短，但词表膨胀。

粒度大致词表规模同一句的序列长度主要代价
字符级几十到几百最长位置多，计算与长距离依赖更重
子词级（主流）约 3 万到 20 万中等依赖训练语料与语言覆盖
词级可达数十万以上最短未登录词、形态变化导致词表膨胀

区间为公开模型的常见量级，用于建立直觉；具体数值以各模型的分词器说明为准。

词表大小怎样影响参数量

输入嵌入表的大小是 V × d_model。以 d_model = 4096 为例：

32,000约 1.31 亿词表较小，序列更长
50,257约 2.06 亿常见英文为主的量级
200,000约 8.19 亿词表很大，单这一层就很占参数

词表变大还会带来一个副作用：每个符号在训练中出现的次数变少，低频符号的向量不容易学好。所以词表规模是效率、覆盖率与学习效果的折中，并非越大越好。总计算量还与序列长度有关：注意力分数矩阵是 n × n。

多语言时要注意什么？

课堂问答提到：如果分词器在多语言混合语料上训练，词表会被多种语言瓜分。如果你只关心其中一种语言，序列可能变长；但跨语言共享的符号（比如通用缩写）也可能带来帮助。因此做多语言工作时，应确认分词器确实在你关心的语言上训练过。

② 编号只是索引，向量才进入计算

还要分清两种“表示”

下面两项区别很重要：

  • 初始 token embedding：同一个 token 通常查到相同的初始向量。
  • 上下文表示：经过后续层后，会根据句子中的其他内容发生变化。例如同一个 bank，可以在不同上下文中表示“银行”或“河岸”。
这里用二维向量方便计算。真实模型的向量通常有更多维度，每个维度通常也没有预先指定的人类含义。

1. Word2vec：一个很窄的神经网络

课件第 35 页的结构只有三层：输入大小 V，隐藏层大小 d，输出大小 V。中间那层就是我们要的词向量。

2. RNN：把顺序信息带进来

词向量本身不知道词序：“孩子抱着泰迪熊”和“泰迪熊抱着孩子”会得到同样的向量集合。RNN 通过一个隐藏状态把“已经读过什么”传递下去：

h_t = f(h_{t-1}, x_t)

课件第 51 页展示了 RNN 能承担的几类任务：生成（输入文本 → 输出文本）、分类（输入文本 → 一个类别）、多分类（每个位置一个标签，如词性）、情感分析、翻译、命名实体识别。

RNN 的两个硬伤

长距离依赖：所有历史都被压进一个固定长度的向量里，反复改写后早期信息容易丢失。比如先说“我的泰迪熊有 3 英尺高”，隔了很多词之后再说“它”，此时“它”指谁已经很难从当前隐藏状态里读出来。

无法并行：h_t 依赖 h_{t-1}，必须一个接一个算，训练慢。这两点正是 Transformer 想要解决的问题。

3. LSTM：加一条更长的“记忆通道”

课件第 52 页提到 LSTM（1997）保留了隐藏状态，但额外引入细胞状态，并用门来控制“写入多少、保留多少、输出多少”。这里给出简化示意，不展开公式：

遗忘门
决定旧记忆保留多少
输入门
决定新信息写入多少
输出门
决定当前输出取多少
细胞状态
一条贯穿时间步的通道，
比隐藏状态更容易长期保存信息

它缓解了长距离依赖，但仍然是顺序计算，也没有彻底解决信息在长序列中被稀释的问题。这是注意力机制出现的直接动机。

4. 早期注意力：翻译时“回头看原文”

课件第 54–55 页介绍 2014 年 Bahdanau 等人的工作。翻译长句时，seq2seq 模型原本只能靠编码器最后那个隐藏状态记住整句，注意力允许解码器在生成每个词时直接读取源句的相关位置：

要生成法语 “lit”（读）时，模型可以直接把注意力放到源句的 “reading” 上，而不必依赖一个被反复压缩的状态向量。这就是后来 Transformer 里 self-attention 的思想来源。

注意区别：这里的注意力连接的是解码器和编码器（cross-attention 的前身，2014 年）；Transformer 的核心创新是把注意力用在同一序列内部（self-attention），并几乎不再依赖循环结构。

训练完只留一张表，网络本身会丢掉

Word2vec 的隐藏层没有激活函数，本质就是“按 ID 取一行向量”。训练结束后，中间那个嵌入矩阵才是产品，其余权重可以丢弃。这解释了为什么它常被叫作“词向量算法”，而不是“语言模型”。

词频太高或太低都不好算：负采样

原始做法要对整个词表做 softmax。词表十万级时，每预测一个词都要算十万个分数。负采样把它改造成一组二分类：

正样本：真实相邻的词对
(agent, learns) → 1负样本：随机抽 5～15 个不相关的词
(agent, apple) → 0→判断“这两个词是否相邻”

这样就不必遍历整个词表，训练速度大幅提升。代价是它优化的是近似目标，而不是完整的 softmax 概率。

顺带认识另两个词向量方法
方法核心做法主要优势主要局限

③ 注意力：这一次，该从谁那里读取多少信息？

注意力到底在做什么：一个通用框架

先不谈 Transformer。人在读句子时会有选择地分配注意力——“小明把书放在桌上，然后他去吃饭，因为他饿了”里的“他”显然指小明，而不是句子里的每个字都同等重要。注意力机制就是把这件事数学化：给每个位置算一个权重，权重高的信息保留得多。

所有注意力都可以写成同一个框架：用 Query 去查 Key，取回 Value。

角色图书馆类比含义
Query（Q）你的检索需求我现在想找什么信息？
Key（K）每本书的标签／索引我能提供什么特征，供你匹配？
Value（V）书里的实际内容匹配上了，我实际给你什么信息？
① Q 与所有 K 做点积 → 匹配分数
② 分数过 softmax → 权重（非负、和为 1）
③ 用权重加权求和 V → 本次的输出

自注意力的六个步骤（带形状）

设序列长度 n、模型维度 d_model、每个头的键维度 d_k。“自”是指 Q、K、V 都来自同一批输入。

步骤做什么形状
①输入 X 分别乘三个可学习矩阵，得到 Q、K、VX: n×d_model → Q,K: n×d_k；V: n×d_v
②Q 与 K 转置相乘，得到每个查询对每个键的分数QKᵀ: n×n
③除以 √d_k 控制数值尺度（维度过大时点积会很大，softmax 会过尖）n×n
④按行做 softmax，每行和为 1n×n 权重矩阵 A
⑤A 乘 V，按权重汇总信息n×d_v
⑥多头时把各头结果拼接，再乘 W_O 回到 d_modeln×d_model

第 ② 步的 n×n 就是注意力开销随序列长度平方增长的原因；第 ③ 步的缩放不影响表达力，只影响优化是否稳定。

展开公式：为什么要做这几步？
分数 s_j = (q · k_j) / √d_k
权重 a_j = exp(s_j) / Σ exp(s_l)
输出 z = Σ a_j v_j

点积衡量经过学习的查询与键的匹配程度。缩放用来控制分数尺度；softmax 把分数变成非负且总和为 1 的权重。最后按权重混合 V。

把所有位置的查询一起计算，就是：

Attention(Q,K,V) = softmax(QKᵀ / √d_k) V

如果共有 n 个位置，Q 与 K 都是 n × d_k，QKᵀ 就是 n × n。每一行对应一个查询，每一列对应一个被读取的位置。softmax 对每一行分别计算。

Q、K、V 从哪里来？

真实模型通过不同的可学习矩阵对输入 X 做投影：Q = XW_Q，K = XW_K，V = XW_V。这里直接给定 K、V 并调整 Q，是为了隔离并看清匹配与汇总的过程。滑块不表示真实模型会让人手动设置查询。

1. 位置信息：同样的词，顺序可能不同

“孩子抱着熊”和“熊抱着孩子”使用相同的词，却有不同的关系。基础全连接自注意力对重排具有置换等变性：重排输入会相应重排输出，它本身没有指定“谁在第几个位置”。

token embedding
[0.4, −0.2, 0.7, 0.1]＋该位置的编码
[0.0, 1.0, 0.0, 1.0]＝送入网络的向量
[0.4, 0.8, 0.7, 1.1]

原始 Transformer 用不同频率的正弦与余弦给位置编码，向量与 token embedding 同维，因此可以逐项相加。

PE(pos, 2i) = sin(pos / 10000^(2i/d_model))
PE(pos, 2i+1) = cos(pos / 10000^(2i/d_model))
方式做法优点代价
固定（正弦／余弦）按公式直接算出，不参与训练不增加参数；新位置也能算出编码可塑性差，外推能力有限
可学习每个位置一个可训练向量灵活，能适配数据受限于训练时见过的最大长度

现代模型多用相对位置方案：RoPE 把位置信息“旋转”进 Q、K，ALiBi 给远距离位置加负偏置。它们改善的是长文本表现，而不是取消位置建模的必要性。

pos 是位置编号；i 是频率组编号。类比时钟：秒针、分针、时针变化速度不同，组合起来能区分更长时间范围。数学上可计算新位置的编码，不保证模型能可靠理解任意长度文本；编码差也不只由相对距离决定。

2. 多头注意力：并行使用多组投影

同一输入 X→头 1：Q₁/K₁/V₁ → Z₁
头 2：Q₂/K₂/V₂ → Z₂
… 各自计算注意力→拼接各头输出→乘 W_O
回到 d_model

类比：卷积层同时用多个卷积核，从不同角度提取特征；多头注意力同时用多组投影，从不同角度读取上下文。差别是注意力不预设“核”的作用范围，权重来自数据。

不同头的投影可以学习不同的信息交互模式，但没有预先指定“这个头负责语法、那个头负责指代”。单个头也可以表达多种关系。若 h=8、d_model=512、每头 d_v=64，拼接后是 8×64=512 维。

常见取值：h = 8 或 16，每头维度 d_k = d_v = d_model / h。也有模型让各头维度之和不等于 d_model，但输出仍会投影回 d_model 才能接下一层。

3. FFN：先升维，再做非线性加工

注意力让不同位置交换信息；FFN 对每个位置自己的向量进行加工。各位置共享同一套 FFN 权重，也可以同时批量计算。

一个位置：d_model→ 线性变换 →d_ff
例如 4×d_model→ ReLU →再线性变换
回到 d_model
FFN(x) = ReLU(xW₁ + b₁)W₂ + b₂
示例：d_model=2，d_ff=4
x=[1, −1]
W₁=[[1,0,1,−1],[0,1,1,1]]
xW₁=[1,−1,0,−2] → ReLU → [1,0,0,0]
W₂=[[1,2],[0,1],[1,0],[−1,1]]
输出=[1,2]（本例偏置都取 0）

如果去掉中间的非线性，两次线性变换可以合并成一次，表达能力就失去了这一步带来的扩展。

为什么说 FFN 占很多参数？

对于标准多头注意力与两层 FFN，假设 d_ff=4d、Q/K/V 总投影宽度为 d，忽略偏置和归一化：注意力约 4d²（四个投影），FFN 约 8d²（d→4d→d），所以 FFN 占这两部分的约 2/3。这个比例不是所有模型总参数的定律：交叉注意力、嵌入表、GQA、门控 FFN 与 MoE 都会改变统计。

4. 残差：原信息与新信息都有通道

深层网络通过这条额外路径更容易传递信息与梯度。它帮助优化，但不能保证任何训练配置下都不发生梯度问题。

5. LayerNorm：沿每个位置的特征维归一化

x=[1,3] → 均值 2，方差 1
(x−均值)/√(方差+ε) ≈ [−1,1]
再乘可学习缩放 γ，加可学习偏移 β

它对每个位置的特征进行处理，不是把所有句子混在一起算均值。由于 ε 和可学习的 γ、β，最终输出不必严格均值为 0、方差为 1。

7. Dropout：训练时随机“关掉”一部分单元

定义：训练时按概率 p 把一部分激活值（或连接）临时置 0，并把保留下来的值放大 1/(1−p) 倍；推理时完全不丢弃，也不放大。

为什么需要：模型参数远多于数据时，神经元容易“互相依赖”——某个特征总由固定的几个单元一起凑出来，换一份数据就崩。随机丢弃逼着每个单元都能独立派上用场，相当于每次训练一个略有不同的子网络，推理时近似把这些子网络平均起来。

例子（p = 0.5）：某一层的激活值 x = [1.2, −0.5, 0.8, 2.0]

单元原始激活随机掩码置 0 后放大 1/(1−0.5)
11.2保留1.22.4
2−0.5丢弃00
30.8保留0.81.6
42.0丢弃00
为什么放大：每个单元的期望输出 = p×0 + (1−p) × x/(1−p) = x
所以训练时“平均幅度”和推理时一致，不必等推理再去补偿

放大这一步叫 inverted dropout，是现代实现的常见做法。另一种写法是训练时不放大、推理时统一乘 (1−p)，数学上等价。

三个常见坑：① 推理时忘记切到 eval 模式，结果会随机抖动；② Dropout 只在训练启用，评估/上线必须关闭；③ p 不是越大越好，0.1～0.5 之间常见，现代大模型往往只用很小的 p，或只在部分位置使用。

相似的正则化还有标签平滑（软化目标分布）与权重衰减（惩罚过大的参数），它们作用于不同环节：Dropout 改的是激活，标签平滑改的是目标，权重衰减改的是参数更新。

8. 标签平滑：不让目标“非 1 即 0”

定义：把 one-hot 的硬目标改成软目标：正确类拿 1−ε，其余 K−1 个类平分 ε。例如 K = 4、ε = 0.1 时，目标从 [1, 0, 0, 0] 变成 [0.9, 0.0333, 0.0333, 0.0333]。

为什么需要：语言里同一句话常常有多种合理续写，“正确答案唯一”这个假设并不总成立。硬目标会驱使模型把 logit 越推越大，追求 100% 自信，容易过拟合、也让概率校准变差。软化目标相当于告诉模型“别那么绝对”。

例子（沿用第 0 节的四个词）：当前预测 p = [0.3125, 0.3489, 0.1433, 0.1953]，正确词是第 1 个。

目标类型目标向量交叉熵损失
硬目标（one-hot）[1, 0, 0, 0]1.163
软目标（ε = 0.1）[0.9, 0.0333, 0.0333, 0.0333]1.201

同一组预测下，软目标的损失更高——因为它还要求模型给其他词留下一点概率。这正是目的：损失不会再被“把正确词推到 1”这一件事主导。

从梯度看更清楚：softmax + 交叉熵的梯度是 p − 目标。

词预测 p硬目标梯度（硬）软目标梯度（软）
可爱（正确）0.31251−0.68750.9000−0.5875
柔软0.348900.34890.03330.3156
阅读0.143300.14330.03330.1100
是0.195300.19530.03330.1620

硬目标下，只有当 p(可爱) 逼近 1、其他逼近 0 时梯度才归零；软目标下，最优解是 p ≈ 软目标（此时损失约 0.435，而不是 0）。所以模型学到的是“比较有把握”，而不是“绝对确定”。

要注意的边界：均匀平滑会把概率平均分给所有其他词，它并不知道“柔软”和“阅读”谁更合理；对语言建模这种“下一个词常常确实唯一”的任务，ε 通常取得很小（如 0.1），或只在特定训练阶段使用。它与蒸馏中的“软标签”不是一回事——后者的软标签来自教师模型的分布。

原始 Transformer 论文在机器翻译任务上报告过标签平滑带来的 BLEU 提升；它属于“训练目标层面”的正则化，与 Dropout（作用于激活）、权重衰减（作用于参数）分工不同。

Pre-Norm 与现代架构仅作补充。理解第一讲时，优先跟踪原始模型的计算顺序。

④ 编码器与解码器：谁在读，谁在写

2017 年的原始 Transformer 是为机器翻译设计的。它把任务拆成两半：读懂源句和写出译文，分别交给编码器和解码器。二者都是“把同样几个子层堆 N 次”，区别在于读取范围和是否访问另一方。

概念 1：编码器（Encoder）

定义：把源语言序列的每个位置转成同时包含整句上下文的表示。它对每个位置都用双向自注意力，不加因果掩码——第 1 个词也能看到最后一个词。

为什么需要：翻译时，理解一句话需要前后文互证。例如判断“苹果”是水果还是公司，得看后面的“发布了新产品”。

源句 token→ embedding + 位置编码 →自注意力（双向）→FFN→ 重复 N 层 →每个源位置一个上下文表示

一个常见误解：编码器不是“把整句压成一个向量”。它输出的是与源句等长的一组向量（每个位置一个），后续交叉注意力正是按需读取其中某几个位置。

概念 2：解码器（Decoder）

定义：根据已经生成的目标词与编码器对源句的表示，逐步预测下一个目标 token。

为什么需要：生成是自回归的：第 t 个词取决于前 t−1 个已生成的词。它必须同时满足两个约束——只能看左边（不能偷看答案），又能读原文。

这两件事由两个不同的注意力子层完成：

子层Q 来自K、V 来自作用
掩码自注意力解码器当前表示解码器当前表示（屏蔽未来）“我已经写了什么”
交叉注意力解码器当前表示编码器输出“原文里哪一部分对当前这个词有用”

为什么交叉注意力的 K、V 来自编码器而不是解码器：解码器是在“查询”原文——它提出问题（Q），编码器提供可被匹配的特征（K）与内容（V）。

概念 3：两个堆叠怎么连接

三个容易忽略的细节：

  • 编码器的输出会被每一层解码器重复读取，不是只传给第一层。
  • 解码器每层都有三块：掩码自注意力 → 交叉注意力 → FFN，每块后面都接残差与归一化。
  • 编码器和解码器的层数可以相同（论文 base 用 N = 6），但参数不共享。

论文 base 配置：N = 6、d_model = 512、h = 8、d_ff = 2048、d_k = d_v = 64，参数量约 6500 万。

概念 4：一次完整翻译的数据流

步骤做什么形状（base 配置，源长 m、目标长 n）
①源句分词 → embedding ＋ 位置编码m × 512
②编码器 N 层：自注意力 → FFNm × 512
③编码器输出（每个源位置一个表示）m × 512
④解码器输入：[BOS] ＋ 已生成词，加位置编码n × 512

概念 5：生成是循环，不是一次吐出一整句

训练时目标文本已知，可以把整句喂进去、用因果掩码并行算损失；推理时没有答案，只能一步一步来：

第几步：
[BOS]？

解码器读完这 1 个位置后，输出层给整个词表打分，概率最高的是 Un。

第一步只有起始标记作为输入，模型给出第一个词。

[BOS]Un？

解码器读完这 2 个位置后，输出层给整个词表打分，概率最高的是 ours。

把刚生成的 Un 接到输入末尾，再预测下一个词。

[BOS]Unours？

解码器读完这 3 个位置后，输出层给整个词表打分，概率最高的是 en。

每多一个词，解码器的输入就长一格。

[BOS]Unoursen？

解码器读完这 4 个位置后，输出层给整个词表打分，概率最高的是 peluche。

注意：之前生成的词可以被反复读取，因为它们都在左侧。

直到模型输出 [EOS]（或达到长度上限）才停止。这也是“训练能并行、生成要串行”的原因。

概念 6：三种架构 = 保留了这个结构的哪几块

架构保留的部分典型模型擅长
Encoder–Decoder①～⑧ 全部原始 Transformer、T5、BART翻译、摘要等“输入→输出”转换
Encoder-only①～③，双向读取BERT分类、抽取、检索等理解任务
Decoder-only④～⑧，去掉交叉注意力GPT、LLaMA、Qwen续写、对话，也能用生成方式做理解任务

第一讲讲的是第一行。今天的主流模型多是第三行：没有独立编码器，输入直接作为序列的一部分参与自注意力。

两处 softmax，两个用途：注意力里的 softmax 在“可读取的位置”上归一化，决定读多少；输出层的 softmax 在“整个词表”上归一化，决定下一个词是哪个。

3. 三代范式：预训练、微调、提示
阶段做法需要的数据换任务时
预训练在海量无标注文本上做自监督目标（如预测下一个 token）极大，通常不需要人工标注不涉及，先得到基座
微调用少量标注数据更新（部分）参数几千到几万条要重新训练、另存一份权重
提示不改参数，把任务写进上下文0 到几个示例改几行文字即可

关键是三者不是互相取代：微调仍是重要的适配手段，提示降低了轻量适配的成本。对话产品通常还包含指令微调等后训练步骤，把“会续写”调成“愿意按指令回答”。

4. 规模、缩放法则与“涌现”

经验研究给出幂律关系：损失随参数量 N、数据量 D、计算量 C 增加而下降，但收益递减（指数约 0.07～0.1 量级）。

Chinchilla（2022）的实践结论是：给定计算预算时，模型与数据要一起放大，常见经验比例约为 每个参数配 20 个 token。例如 70B 参数配约 1.4T token。

“涌现能力”（上下文学习、思维链等在某个规模后突然出现）是一个流行说法，但也有研究认为它可能是评测指标不连续造成的错觉。把它当作规划参考，而不是物理定律更稳妥。
5. 今天的模型改了哪些零件
部件原始 Transformer（2017）现代常见做法改动目的
整体结构编码器 + 解码器多为 decoder-only任务形式统一，结构更简单
归一化位置Post-NormPre-Norm深层训练更稳
归一化方法LayerNormRMSNorm 等少算均值，速度更快
位置编码正弦／余弦RoPE 等相对位置方案改善长文本表现
激活函数ReLUSwiGLU 等门控形式效果与效率更好
注意力标准多头GQA／MQA减少推理时缓存开销
FFN稠密MoE 混合专家参数多但每次只激活一部分

生成时还会用到 KV Cache：把已算过的 K、V 存起来，新 token 只算增量。它不改变模型数学上的输出，只改变计算与显存的开销方式。这些细节属于后续讲次与专门资料。

6. 能力分层：哪些靠模型，哪些靠外部系统
层次例子来源
基础能力理解、世界知识、多语言、代码预训练自然获得
涌现／指令能力上下文学习、分步推理、指令遵循规模 + 后训练
增强能力任务分解、工具调用、自我检查外部系统：工具、检索、循环

这也解释了为什么同一个基座模型，套上工具与执行循环后“看起来更聪明”：它跨到了第三层。模型本身没有因此改变。
