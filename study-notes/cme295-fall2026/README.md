## 后续如何一起学习

每次可以从一个概念、一页课件或一个具体问题开始：

1. 对照课件确认问题及必要的前置知识。
2. 先解释直觉，再用小例子、公式或矩阵维度验证。
3. 通过简短问题检查理解；有需要时补充可运行示例。
4. 把讨论结果、容易混淆的地方和未解决问题更新到对应讲次笔记。

笔记区分课程内容、补充解释和学习进度。讨论中出现的问题不自动视为已经掌握；需要复习的内容继续保留。
