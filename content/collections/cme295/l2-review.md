## 1. 一个请求怎样经过本讲的组件？

假设给 decoder-only 模型提示：“熊 A 在 2024 年 4 岁，请输出 2025 年年龄的 JSON。”

1. 提示与模板分词，检查输入和输出预算。
2. token 进入模型；各层用位置机制（例如 RoPE）构造带相对位置信息的匹配。
3. 注意力按允许范围读取上下文，FFN 或 MoE 处理每个位置。
4. Pre-Norm、RMSNorm 等组件按具体架构执行，不是推理时临时选择的按钮。
5. 输出隐藏表示投影为 logits，温度和候选规则调整选择方式。
6. 若支持约束解码，屏蔽不符合 JSON／Schema 的续写。
7. 新 token 追加到上下文；KV Cache 复用历史结果。
8. 到结束条件停止，再检查 age 是否等于 5，而不只检查 JSON 可解析。

这是教学组合例子，不表示所有模型都使用 MoE、GQA 或同一套归一化。

## 2. 六条主线总表

| 课件章节 | 记住的核心 | 易错点 |
| --- | --- | --- |
| 模型家族 | 编码表示或因果预测；输入可见范围不同 | “decoder-only 不理解输入” |
| 缩放法则 | 参数、数据、训练与推理预算共同影响方案 | “模型更大一定省钱” |
| 专家路由 | 每个 token 可只执行少数专家 | “总参数等于每次激活参数” |
| 架构优化 | 位置、访问范围、缓存、共享头、归一化各有职责 | “GQA 就是缩短窗口” |
| 解码 | logits 之后还要选择候选 | “Top-p=0.8 就是保留 80% 个词” |
| 提示与推理 | 不改参数地组织上下文、示例、采样聚合 | “解释流畅就是内部推理真实且正确” |

## 3. 自测与解析

<details><summary>题 1：BERT 的 MLM 为什么可以看右侧？</summary><p>输入被选位置被遮盖或破坏，任务是利用周围上下文恢复原词。它不是从未遮住的目标位置复制答案；实现还需要遵守预测位置与损失构造。</p></details>
<details><summary>题 2：Top-2 路由概率 [0.55,0.25,0.15,0.05]，若重新归一化，前两位权重是多少？</summary><p>保留质量 0.8，权重分别 0.6875 与 0.3125。应明确具体模型是否采用这套归一化约定。</p></details>
<details><summary>题 3：KV 头从 8 减到 2，其他条件不变，缓存减少多少？</summary><p>简化字节公式与 h_kv 成正比，缓存变成原来的 1/4；端到端速度不保证提高 4 倍。</p></details>
<details><summary>题 4：logits 排序不变，为何调温度会改变生成？</summary><p>除以正温度不改变排序，却改变 softmax 概率差距；按分布采样时，候选被抽中的概率变化。</p></details>
<details><summary>题 5：正弦编码的点积只与 m−n 有关，能说所有注意力也只与距离有关吗？</summary><p>不能。这个性质首先是 PE 自身的点积；实际 token 内容、投影与其他层还会影响分数。RoPE 推导保留内容向量和相对旋转项，并不是抹掉内容。</p></details>
<details><summary>题 6：用 5 次生成多数投票，能保证答案更正确吗？</summary><p>不能保证。多个答案可能共享同一误解，应使用有意义的多样性并加入独立核验；成本通常也会增加。</p></details>

## 4. 字幕术语校正

| 字幕表现 | 正确术语 | 含义 |
| --- | --- | --- |
| 法学硕士 | LLM | 大语言模型 |
| 变压器 | Transformer | 神经网络架构 |
| 递归、自動回應、自動遞增 | Autoregressive | 自回归，逐 token 条件生成 |
| 训练失败次数、flops 失败 | FLOPs | 浮点运算总次数 |
| 分子轨道、教育部、emo | MoE | 专家混合 |
| 繩子、ROP | RoPE | 旋转位置编码 |
| 不在場證明 | ALiBi | 注意力线性偏置 |
| 密钥 | Key | 注意力的键，非密码学密钥 |
| 负責人、头部 | Head | 注意力头 |
| 术前／术后正常化、色情内容 | Pre-Norm / Post-Norm | 归一化放置顺序，字幕严重误译 |
| 哈希堆叠中的针 | Needle in a Haystack | 长上下文检索评测思路 |

## 5. 哪些表述需要加边界？

- 可计算更长位置的编码，不等于模型能可靠外推到无限上下文。
- token 效率更好，不等于每个 token 的计算或服务成本更低。
- 专家名是子网络，不保证训练出人工学科分工。
- RMSNorm 不要求输出中心化，Pre-Norm 也不是一种归一化公式。
- 温度为零不等于服务环境中绝对可复现。
- 约束解码限制形式，不证明事实或业务正确。
- 更多上下文、更多示例、更多采样均需要实测收益与成本。
