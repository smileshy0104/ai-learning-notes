## 1. 为什么位置不能省？

对应 PDF 第 51–74 页。基础全连接自注意力的计算没有显式输入顺序标签。交换输入顺序时，结果也会相应交换，而不是自动知道“谁在第一个位置”。这叫置换等变性。

“熊抱着孩子”和“孩子抱着熊”需要不同关系表示。因此要让网络利用位置信息。因果掩码本身也限制可见范围；下面讨论的是明确的位置建模机制。

## 2. 可学习的绝对位置

每个位置编号对应一个可学习向量：`输入 xₘ = token_embedding + position_embedding(m)`。

例子：同一个词在位置 0 与 20 查到相同 token embedding，但加上不同的位置向量后，送入网络的表示不同。

代价是固定位置表的范围。训练只定义了位置 0–511，不能直接查出不存在的第 1000 行。扩展表、插值和继续训练是可能的工程措施，不是逻辑上永远不能变长。

## 3. 正弦编码：快慢不同的“指针”

PDF 第 55–65 页用时钟类比：高频分量快速变化，低频分量慢慢变化。

```text
ωᵢ = 10000^(−2i/d)
PE(m,2i) = sin(mωᵢ)
PE(m,2i+1) = cos(mωᵢ)
```

m 为位置，i 为二维分组索引，d 为偶数维度。以 d=4 为例，两组频率是 1 和 0.01。

| m | PE(m)（近似） |
| --- | --- |
| 0 | [0, 1, 0, 1] |
| 1 | [0.8415, 0.5403, 0.0100, 1.0000] |
| 2 | [0.9093, −0.4161, 0.0200, 0.9998] |

### 为什么点积涉及相对距离？

利用 `sin a sin b + cos a cos b = cos(a−b)`：

```text
PE(m) · PE(n) = Σᵢ cos((m−n)ωᵢ)
```

只比较位置编码自身时，点积是相对位置差的函数。**这不等于完整 token＋位置经过任意投影后的注意力分数只由距离决定**；token 内容与交叉项仍有影响。

补充直觉：d=4 时，PE(0)·PE(1)≈1.5403，PE(10)·PE(11)也是约 1.5403。平移两个位置，不改变这对编码的点积。

“距离越远一定越不相似”过于绝对，余弦是周期的，可能反弹。公式能为任意新位置求值，也不保证模型对任意长文本都能可靠外推。

## 4. 把位置放进注意力分数

原来的加法位置编码会沿整个网络流动。另一种思路是直接修改注意力里的匹配分数：

```text
score(m,n) = qₘ·kₙ / √dₖ + b(m,n)
```

| 机制 | 如何加入位置 | 关键区别 |
| --- | --- | --- |
| T5 相对位置偏置 | 按头、按相对距离桶学习偏置 | 不是为每个任意距离都单独学习一项 |
| ALiBi | 给因果过去位置加线性距离惩罚 | 斜率按头设计，不用训练绝对位置表 |
| RoPE | 按位置旋转 Q/K，再做点积 | 位置信息进入相对旋转 |

ALiBi 的因果教学写法：`b(m,n)=−sₕ(m−n)`，n≤m、sₕ>0。斜率 0.5 时，当前位置及前 3 个位置偏置依次为 0、−0.5、−1、−1.5。内容得分仍可能克服距离惩罚。

## 5. RoPE：先理解二维旋转

RoPE = Rotary Position Embeddings。字幕里的“繩子”是把 rope 当成普通英文翻译了。

```text
R(φ) = [[cosφ, −sinφ],
        [sinφ,  cosφ]]
R(φ) [x,y]ᵀ = [x cosφ−y sinφ, x sinφ+y cosφ]ᵀ
```

**例子**：向量 [1,0] 旋转 90° 得 [0,1]；长度仍为 1。真实位置角通常以弧度计算，此处用度数只是帮助理解几何。

## 6. 为什么两个旋转只剩相对位置？

以下使用**列向量**约定，与课件图中的行向量记法可能转置，实质相同：

```text
q̃ₘ = R(mθ) qₘ
k̃ₙ = R(nθ) kₙ
q̃ₘᵀ k̃ₙ = qₘᵀ R(mθ)ᵀ R(nθ) kₙ
          = qₘᵀ R((n−m)θ) kₙ
```

因为旋转的转置相当于反向旋转，两个绝对角度相消，剩相对角度。

**手算例子**：θ=30°，m=1、n=3，q=k=[1,0]。

```text
q̃=[cos30°,sin30°]≈[0.8660,0.5]
k̃=[cos90°,sin90°]≈[0,1]
点积≈0.5=cos60°
把 m,n 同时加 5，点积仍≈0.5
```

这里只冻结 q、k 看位置项。真实模型在不同位置上的内容向量也会变化，不意味着所有相距两格的词都得到同一分数。

## 7. 高维版本与长距离的边界

高维 RoPE 把偶数维向量分成二维块，每块按不同频率旋转，例如 [x₀,x₁]、[x₂,x₃]。通常旋转 Q 与 K，V 不作相同旋转。

课件第 74 页讨论长期衰减的相对上界。不要误读成：每个头、每对词的实际注意力权重都随距离单调下降。多频率叠加、内容方向和 softmax 的竞争都在影响结果。
