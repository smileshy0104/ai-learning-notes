Token representation

token ID 只是查表索引，不携带“编号越近、意思越近”的语义。one-hot 能标记身份；learned embedding 则把每个 token 映射到可学习的稠密空间。

表示示例优点限制
One-hot可爱 → [0,1,0,0]明确、简单不同 token 在 one-hot 空间正交
Embedding可爱 → [0.7,0.9,−0.1]可表达相似性需要训练才能得到有用方向
静态 embedding 是查出来的；Transformer 经过上下文计算后的表示，是结合整句算出来的。不要把两者混为一谈。

Self-attention

一个位置用 Query 查询其他位置的 Key，再按权重汇总 Value。完整公式：

Attention(Q,K,V) = softmax(QKᵀ / √dₖ)V

QKᵀ 得到 n×n 分数矩阵；每行 softmax 后是“当前查询位置从其他位置读取多少”。

两处 softmax，作用对象不同

注意力 softmax 在“位置”上归一化，用来决定读取比例；输出 softmax 在“词表”上归一化，用来决定下一个 token 的概率。

Encoder / Decoder

原始 Transformer 里，Encoder 负责把源句变成上下文表示；Decoder 通过掩码自注意力读取已有译文，通过交叉注意力读取 Encoder 输出，再预测下一个 token。

Encoder · 读

双向 self-attention → FFN，输出每个源位置的上下文向量。

Decoder · 写

causal self-attention → cross-attention → FFN，逐 token 生成。

序列与上下文

RNN 逐步更新隐藏状态，LSTM 加入门控与细胞状态改善信息保留。循环模型的时间步相互依赖；自注意力则让允许访问的位置直接交互，缩短信息传递路径。它们都可以从相同的初始 token embedding 出发计算上下文表示。

其他模型组件

位置机制让模型利用顺序；多头注意力用不同投影汇总信息；FFN 对每个位置独立进行共享的非线性变换；残差保留直接通路，归一化帮助控制特征尺度。它们共同组成 Transformer 层。

训练与推理

训练：前向 → 损失 → 反向 → 更新。推理：只做前向，参数冻结。这个区别会影响显存、延迟、Dropout 是否启用，以及是否可以计算梯度。

应用与 Agent

模型生成下一步决策，外部系统执行工具，将结果加入上下文，再继续或结束。这个循环把语言模型接入文件、搜索和程序等工具，但是否可靠仍需实际验证。
