把个人笔记变成共同学习的地方

三种入口，同一个目标：
让 AI 知识更容易理解。

选择适合你的学习体验。三套原型使用同一批真实主题：机器学习基础、Transformer、注意力与模型训练。它们展示不同的信息结构，所有示例数据仅用于教学。

01 / Guided learning

循序 · 课程学习站

从一条明确的学习路线出发。课程、章节、概念和实验依次展开，适合初学者跟着读。

进入课程站 ↗
02 / Knowledge reference

知页 · 知识文档站

概念拥有自己的地址，目录和正文并排。适合详细阅读、查找公式和分享某个知识点。

进入文档站 ↗
03 / Connected knowledge

星图 · 知识地图站

先看概念之间的依赖，再选择下一步。适合跨主题探索、复习和寻找知识缺口。

探索知识地图 ↗

怎么选？

三种设计可以组合。推荐以课程站为入口、文档站为正文，知识地图作为辅助。

比较维度循序 · 课程站知页 · 文档站星图 · 地图站
主要问题我应该从哪里开始？这个概念到底是什么？这些知识怎样连接？
内容组织课程 → 讲次 → 学习单元主题 → 概念 → 公式 / 实验依赖关系 → 路线 → 概念
最适合初学与连续学习深入阅读、检索与精确分享探索与复习

先做好阅读体验，再加入社区功能。
